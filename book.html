卷首语 · 一份写给"想知道该读什么"的人的清单

信息学竞赛最不缺资料。洛谷上有两万多道题，Codeforces 上有上万道，OI Wiki 有上千个词条，国家集训队论文从 1999 年攒到今天已经两百多篇，再加上各种教材、课件、博客、视频课——一个刚入门的学生面对这些，第一反应从来不是"没东西学"，而是"我该从哪一个开始"。

这本书想解决的就是这个问题。它不教你算法，也不替你写代码。它做的是一件更基础、也更容易被忽视的事：把散落在互联网各个角落的资料，一条一条地收拢起来，分好类，标好难度、用途和效果，然后排成一份可以按图索骥的目录。你可以把它理解成一张地图——地图不能代替走路，但能让你少走三年弯路。

全书收录 307 份资料，覆盖教材与专著、官方文档与规则、在线平台与题库、集训队论文与专题讲义、历年真题与题解、课程与视频、工具与环境、社区与期刊八个大类。每一条都标注了四件事：

  • 适用竞赛类别——从 CSP-J 到 IOI，你处在哪一段，就只看哪一段的书目；
  • 任务需求——入门自修、体系学习、专题突破、赛前冲刺、教练备课、查漏补缺、实战训练；
  • 作用效果——速查、深耕、实战、方法论；
  • 获取途径——免费、开源、纸质、付费、需权限。

这三重分类不是装饰。同一本书，对初三刚入门的学生是"体系学习"，对省队选手可能只是"速查"；同一份题库，对教练是"备课素材"，对选手是"实战训练"。所以本书没有给出唯一正确的读法，而是给了三套交叉索引（第三编），你可以从任何一个维度切进去。

最后提醒一句：目录的价值在于被使用，而不是被收藏。如果你读完这本书只记住了一件事，我希望是——先选定一条路线，把它走完，再回来看下一段。资料永远读不完，但一条路是可以走完的。

PART I

竞赛体系与备考路线

先看清赛道，再谈资料。本编四章回答四个问题：这条赛道分几段、每段考什么、大纲怎么读、一年怎么排。

第 1 章　信息学竞赛全景地图

1.1 一条被切分成五段的赛道

中国的信息学竞赛体系，本质是一条从"校内兴趣"通向"国家队"的漏斗。每一段都有明确的晋级条件，也都有对应的备赛资料。搞清楚自己在哪一段，比盲目刷题重要得多。

CSP-S（提高级）CSP-J/S 认证 · 提高级9 月初赛 / 10 月复赛第一轮资格测试 + 第二轮上机 4 题 4 小时成绩作为 NOIP 报名与省选资格的重要依据

1.2 每一段真正在考什么

很多人把这条赛道理解成"难度递增"，这只对了一半。更准确的说法是：每一段考的能力维度不同。

CSP-J 考的是"能不能把想法写成正确的代码"。题目模型直白，暴力往往能拿部分分，真正的门槛是代码基本功：数组边界、循环范围、long long 溢出、多组数据清空。这一阶段刷题量比看书重要。

CSP-S 考的是"能不能识别出这是哪一类问题"。题目开始包装，同一道题可能既是图论又是 DP。这一阶段的瓶颈不在算法数量，而在建模——看到"最少代价使所有点连通"要能立刻想到最小生成树，看到"选与不选且互相制约"要能想到 2-SAT 或最小割。

NOIP 考的是"稳定的发挥"。四道题里通常两易一中一难，绝大多数人的失分不是不会，而是会做的题写挂了、该拿的部分分没拿。这一阶段最该练的是对拍、造数据、估复杂度。

省选 考的是"知识面的完整度"。数据结构、字符串、数论、多项式、计算几何，任何一块空缺都会在某一轮爆炸。省选是全书资料密度最高的一段，也是"书单"最能发挥作用的一段。

NOI 考的是"思维与工程的复合能力"。题目往往没有现成套路，需要自己构造算法，并且要在 5 小时内写出 300 行不出错的代码。这一阶段看的不再是教材，而是集训队论文——那里有前人总结的思维工具。

1.3 一张图看清资料与阶段的关系

把本书收录的 307 份资料按适用阶段统计，会看到一个明显的不均衡：面向 CSP-S 与 NOI 的资料最多，面向 CSP-J 与 IOI 的最少。这不是收集偏差，而是客观现实——中间段的人最多，写资料的人也最多。

阶段资料特点本书对应章节建议投入

一个常见误区是"提前读高阶段的资料"。省选讲义给刚学完 CSP-J 的学生看，结果只有一个：看不懂，然后怀疑自己不适合。正确的顺序永远是先把当前阶段的资料吃到饱，再向上够一级。

第 2 章　NOI 大纲与 1—10 级难度体系

2.1 大纲是什么，为什么必须读

《全国青少年信息学奥林匹克系列竞赛大纲》（简称 NOI 大纲）由中国计算机学会组织编写，是命题的唯一官方依据。它把全部知识点按难度分成 1 到 10 级，并对应到三个竞赛层级：

  • 入门级（对应 CSP-J）：1—5 级；
  • 提高级（对应 CSP-S、NOIP）：5—8 级；
  • NOI 级（对应省选、NOI、IOI）：8—10 级。

读大纲的最大收益不是"知道要学什么"，而是知道什么不用学。竞赛资料里充斥着远超考纲的内容（可持久化平衡树、动态图连通性、各种冷门构造），初学者很容易陷进去。大纲相当于一条护栏：护栏外的知识不是没用，而是投入产出比在当下不划算。

2.2 2025 版的主要变化

2025 版大纲做了一次幅度不小的调整，这些变化直接改变了备赛优先级，值得单独记下来：

层级变化对备赛的影响
提高级新增 bitset状态压缩与集合运算的常规工具，位上跑 DP 的题型会变多
新增 扫描线矩形面积并、区间覆盖类问题从"技巧"升格为"考点"
新增 Manacher由 NOI 级下放，回文题不再只能靠哈希硬做
新增 多维 DP二维以上的状态设计进入提高组范围
NOI 级新增 基与线性基异或最值、线性空间相关问题成为明确考点

删除 二维线段树树套树的教学重心转向其他组合

入门级新增 前缀和（3 级）从"技巧"变为"基础"，必须早学

2.3 把大纲翻译成学习顺序

大纲是按知识点罗列的，不是按学习顺序。真正可执行的做法是把它重排成四条纵向主线，每条主线内部严格由浅入深：

主线内容与顺序对应级别
语言与基础输入输出 → 数组与字符串 → 函数与递归 → 结构体与指针/引用 → STL 容器 → 复杂度分析1—3 级
算法思想枚举 → 模拟 → 排序 → 二分与二分答案 → 贪心 → 前缀和与差分 → 递推与 DP 入门 → 搜索与剪枝2—5 级
数据结构栈与队列 → 链表 → 并查集 → 堆 → 树状数组 → 线段树 → 平衡树 → 可持久化 → 树链剖分3—9 级
图论与数学图的存储与遍历 → 最短路 → 最小生成树 → 拓扑排序 → 连通性 → 二分图 → 网络流 → 数论 → 组合计数 → 多项式 → 计算几何4—10 级

四条主线不必齐头并进，但不能长期缺一条。省选翻车最常见的原因，就是"DP 很熟、图论没学"，或者"数据结构全会、数学推不动"。

2.4 用大纲做自测

给每个知识点打三种状态：不会 / 会用 / 能讲清。"会用"指能做模板题；"能讲清"指能说出它为什么正确、复杂度怎么来的、边界在哪。只到"会用"的知识点，在考场上换个包装就会崩。

建议每三个月做一次全量自测，把状态记在纸上。你会发现进步不是均匀的——某些专题会突然从"不会"跳到"能讲清"，另一些则长期卡在"会用"。后者就是下一步的突破口。

第 3 章　一年从零到 NOI：四阶段路线图

3.1 为什么是"四阶段"而不是"十二个月"

按月排计划几乎必然失败，因为学习速度不是线性的：入门期一个月能推进一大截，专题期一个月可能只啃下一个知识点。所以本书按能力状态而不是日历切分阶段，每个阶段有明确的进入条件和退出条件。时间只是参考。

阶段目标状态进入条件退出条件
一 · 打底能把想法无 bug 地写成代码会基本语法CSP-J 真题稳定 250+；模板题一次 AC 率 ≥ 80%
二 · 建模看到题能识别类型并选对武器完成阶段一CSP-S 真题稳定 200+；提高组知识点自测"会用"≥ 90%
三 · 攻坚掌握省选全套工具，能独立推出非模板题完成阶段二省选真题两轮各能做出 1.5 题以上
四 · 冲刺稳定输出，考场不掉链子完成阶段三五次以上 5 小时全真模拟，成绩方差收敛

3.2 阶段一：打底（约 2—3 个月）

核心任务只有一个：把代码写对。这个阶段不需要学任何"高级算法"，需要的是把循环、数组、函数、递归写到肌肉记忆。题目难度控制在"想一想能写出来"的范围，追求的是一次通过率而不是题目难度。

推荐材料：一本入门教材通读（第 5 章）、一个入门题库按章节刷（第 7 章）、一套入门视频课跟完（第 10 章）。三者选一套主线，另外两套只做补充，千万不要同时开三套。

这个阶段最常见的错误是"看懂题解就等于会了"。判断标准很简单：关掉题解，从空白文件开始，能不能在 20 分钟内写完并 AC。不能，就是不会。

3.3 阶段二：建模（约 3—6 个月）

这一阶段要建立的是题型与武器的映射表。做法不是背，而是"每做完一道题，写一句话总结：这题的关键转化是什么"。积累到 100 句，你会发现自己开始能在读题时预测解法。

训练结构建议：专题（60%）+ 比赛（25%）+ 真题（15%）。专题按第 8 章的题单逐个攻破，每个专题做 15—25 题，做到"看见关键词就知道用哪套模板"。比赛用洛谷月赛、Codeforces Div.2/3，重点不是名次，而是赛后把没做出来的题补掉。

此阶段应完成 CSP-S 与 NOIP 近五年真题各一遍。做真题时严格计时，做完写复盘（见第 4 章）。

3.4 阶段三：攻坚（约 4—6 个月）

省选的难点在于"知识面 + 思维"。知识面靠清单式补全（第 2 章四条主线），思维靠读论文（第 8 章）。

建议的做法是每周一篇论文 + 一套省选真题。论文不要只读，要"讲"——合上文档，用自己的话把核心思想讲一遍，讲不通的地方就是没读懂。真题按省成套做，先做本省近五年，再做 ZJOI / SDOI / SCOI 这些难度较高的卷子。

这一阶段会经历明显的平台期：题目做不出来，论文看不懂，比赛一直挂。这是正常的，也是筛选发生的地方。有效的应对不是加大题量，而是降低题目难度、提高复盘质量——把一道题彻底吃透，胜过囫囵做十道。

3.5 阶段四：冲刺（约 1—2 个月）

冲刺期不学新东西。全部精力放在三件事上：

  1. 全真模拟：每周至少两次，5 小时、断网、只用考场环境（NOI Linux）。目的是让身体适应长时段高强度思考。
  2. 模板复写：把所有常用模板从零默写一遍，包括线段树、树剖、网络流、AC 自动机、NTT。考场现推等于送分。
  3. 错题回炉：把过去半年的错题按知识点归类，只看不写，确认每个坑都记得。

同时要开始练"策略"：开题顺序、部分分分配、什么时候放弃、什么时候对拍。这些在考场上值 50 分以上，却几乎没人专门练。

第 4 章　训练方法：刷题、比赛与复盘

4.1 刷题量的真相

"刷够 1000 题就能进省队"是流传最广的误解。题量当然重要，但真正决定水平的是有效题量——即"独立想出解法并一次写对"的题。抄题解刷完的 1000 题，有效题量可能不到 200。

注意"其中"两列之和小于总量：剩下的部分是自由刷题，用来保持手感与扩展视野。

4.2 一道题该怎么用

同一道题，用法不同，收益差十倍。本书建议的四步法：

  1. 限时独立思考（20—40 分钟）。写下所有想到的方向，哪怕最后没做出来。这一步训练的是"在没有提示的情况下探索"。
  2. 看题解，只看关键转化。看到"啊，原来是这个"就停，剩下的自己想。整篇读完等于没读。
  3. 关掉题解重写。从空白文件开始，写完自己造数据测。写不出来说明第 2 步看多了。
  4. 写一句话总结。格式固定："这题的关键是把 X 转化成 Y，用 Z 维护。" 攒到 100 句，你的解题直觉就成型了。

这四步做完一道题平均要 60—90 分钟。相比"看题解 + 抄代码"的 15 分钟，效率看起来低，但前者留下的东西是后者的五倍以上。

4.3 比赛怎么打才不浪费

比赛的价值有 70% 在赛后。一场 Codeforces，真正该花时间的是"补题"而不是"打完看 rating"。补题的正确顺序：

  • 赛时没思路的题：先补，因为它暴露的是知识或思维缺口；
  • 赛时想到了但写挂的题：其次补，它暴露的是实现能力；
  • 赛时没时间做的题：最后补，它只是速度问题。

补完题要读官方 Editorial，重点看"出题人是怎么想到这个解法的"——这一步才是把别人的思维装进自己脑子的过程。

4.4 复盘模板

每场比赛、每套真题之后填一张表，五分钟就够。坚持三个月，你会有一份极其精准的个人弱点清单。

项目记录内容
失分类型不会 / 想错 / 写挂 / 没时间 / 读错题（五选一，逐题标注）
知识点这道题考的具体知识点（写到二级，如"DP-斜率优化"）
关键转化一句话：题目的哪一步是我没想到的
代码问题具体到行：数组开小 / 未开 long long / 多测未清空 / 边界写反
下次动作可执行的一步，如"本周补完斜率优化 10 题"

"写挂"是最值得统计的一项。绝大多数人的失分不在难题，而在会做的题上丢 40—60 分。把最近十次模拟的"写挂"原因列出来，你会发现高度重复——通常是三四个老毛病。改掉它们，比多学一个算法划算得多。

4.5 关于对拍

对拍是竞赛里性价比最高的工程习惯，却在学生中普及率极低。一个标准对拍需要三样东西：暴力程序（保证正确但慢）、正解程序、随机数据生成器。运行几百组，比对输出。

什么时候必须对拍：涉及复杂数据结构、涉及大量边界情况、涉及贪心或 DP 的正确性不确定。什么时候可以不对拍：题目简单、样例已覆盖、时间紧张到必须取舍。

练对拍的最好方式是在平时刷题时就写，而不是考场上临时抱佛脚。第 11 章收录了对拍脚本与相关工具。

第 18 章　常见问题三十问

关于入门

1. 零基础可以直接学 C++ 吗？可以。竞赛用的 C++ 是子集，不需要学完整个语言。先掌握输入输出、循环、数组、函数，就可以开始做题。

2. 要不要先学 Python？不建议。竞赛环境以 C++ 为主，Python 在时限上吃亏。若已会 Python，转 C++ 大约需要两周。

3. 第一本书选哪本？看第 5 章标注为"CSP-J / 入门自修"的条目，任选一本通读，不要同时开两本。

4. 一天该刷几题？入门期 3—5 题（含思考时间），专题期 2—3 题（要写总结），冲刺期以套卷为主。

5. 看不懂题解怎么办？降一个难度。连续三道题都看不懂题解，说明当前难度区间选错了，不是你的问题。

关于训练

6. 刷题是求量还是求质？前期求量（建立手感），中期求质（建立映射），后期求稳（减少失误）。

7. 需要背模板吗？常用模板必须能默写：线段树、树剖、并查集、最短路、网络流、KMP、NTT。考场现推风险极高。

8. 对拍真的有用吗？有用，而且是被严重低估的一项。详见第 4.5 节。

9. 一定要打 Codeforces 吗？强烈建议。它的 rating 体系是目前最可靠的第三方水平标尺，且题解质量高。

10. 中文题和英文题哪个优先？前期中文（降低语言负担），后期必须练英文（NOI/IOI 题面、论文都是英文或英文术语）。

11. 纸质书和电子版怎么选？教材买纸质（便于反复翻），工具书用电子版（便于检索）。

12. 视频课看多少合适？视频只用来"破冰"，一个知识点看一节就够，剩下时间必须动手。

关于比赛

13. 第一轮（初赛）怎么准备？近五年真题各做两遍，错题按知识点归类。阅读程序题是最大失分点，要专项练。

14. 提高组一等奖大概什么水平？能稳定做出 NOIP 前两题，第三题拿部分分。折算下来约 Codeforces 1600—1800。

15. 省队门槛大概什么水平？强省约 Codeforces 2200+，且知识面无明显缺口。

16. 比赛时该先做哪题？先通读四题（10 分钟），按"有把握 → 有思路 → 有部分分 → 无思路"的顺序做。

17. 什么时候该放弃一道题？投入 40 分钟无实质进展，或已写出但调不出且剩余时间不足 60 分钟时，转去做部分分。

18. 部分分怎么拿？先看数据范围，把 n ≤ 20 的暴力、n ≤ 1000 的 O(n²)、特殊性质（链、树、无修改）分别写掉，通常能拿 40—60 分。

19. 考场上要不要对拍？会做的题写完就拍，尤其是数据结构题。前提是平时练过。

20. 挂了一场很重要的比赛怎么办？复盘，找出可归因的具体原因（不是"我太菜"），然后继续。竞赛是多次博弈，单场结果的信息量很低。

关于资源与方法

21. 资料太多学不完怎么办？本书的存在就是为了解决这个。选一条路线，走完再看下一条。

22. 集训队论文什么时候开始读？省选阶段。太早读不懂，太晚来不及。

23. 论文读不懂怎么办？先读同主题的 OI Wiki 词条打底，再读论文。顺序反了会很痛苦。

24. 需不需要学 Linux？需要。NOI 系列赛事使用 NOI Linux，至少要会编译、运行、文件读写、简单调试。

25. 要不要学算法竞赛以外的编程？有余力可以，但优先级低于竞赛本身。工程能力在 NOI 之后补更高效。

26. 数学要学到什么程度？组合计数、初等数论、概率期望是必需；线性代数在 NOI 级必需；微积分基本不需要。

27. 英语差怎么办？竞赛英语是"术语英语"，把 200 个高频术语背下来，读题面就没有障碍了。

28. 家长能帮上什么？提供稳定的时间与环境，帮忙筛选资料（本书可代劳），不要干预训练方法。

29. 教练最该看哪几章？第 2 章（大纲）、第 8 章（论文与讲义）、第 13—15 章（三套索引）、第 16 章（清单）。

30. 这本书会更新吗？会。资料在变，大纲在变，本书按赛季更新。请以最新版本的编号为准。
