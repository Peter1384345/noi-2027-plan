# 开机自启项清单与停用建议

扫描时间：2026-09-14 22:17 ｜ 扫描范围：注册表 Run 键、启动文件夹、计划任务（登录/开机触发）、自动启动服务

> 说明：启动文件夹为空；Windows 系统自带计划任务（Microsoft\Windows\ 下约 27 项）均属系统机制，不建议停用，故未逐一列出。以下只列第三方项目和值得关注的系统服务。

---

## 一、注册表启动项（登录时自动运行）

| 程序 | 来源 | 作用 | 建议 |
|---|---|---|---|
| SecurityHealth | HKLM | Windows 安全中心托盘图标 | ✅ 保留 |
| RtkAudUService | HKLM | Realtek 音频后台服务 | ✅ 保留（停用可能影响音频设置） |
| **Tabbit Browser**（`--no-startup-window`） | HKCU | Tabbit 浏览器后台常驻，加快启动 | ⛔ 可停用 |
| **Coze 桌面版**（`--open-at-login`） | HKCU | Coze 开机自动打开 | ⛔ 可停用 |
| **Microsoft Edge**（`--no-startup-window`） | HKCU | Edge 后台常驻、预启动 | ⛔ 可停用（代价是首次打开稍慢） |

## 操作提示

- 注册表启动项：可在「任务管理器 → 启动应用」中直接禁用，比改注册表更安全直观。
- 计划任务：`taskschd.msc` 中找到对应任务 → 右键"禁用"（不要删除，便于恢复）。
- 服务：`services.msc` → 右键"属性" → 启动类型改为"手动"或"禁用"。改手动比禁用更稳妥（需要时仍会被拉起）。
- 建议每次只停用 2~3 项，重启观察 1~2 天，确认无异常再继续，出问题随时可改回。
