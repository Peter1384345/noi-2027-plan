# 0003 · 稀疏表 Sparse Table (O(1) RMQ 与分块降空间)

> 一句话结论：稀疏表用 **O(n log n)** 预处理换取 **O(1)** 静态区间最值查询——靠的是"最值可重复贡献"
> （幂等性），让两段**允许重叠**的 2^k 区间拼出答案；若空间是瓶颈，分块 ST 用 3n 空间做到准 O(1)。

---

## 1. 为什么它"高效"

| 维度 | 朴素扫描 | 线段树 | 稀疏表 ST | 分块 ST |
|---|---|---|---|---|
| 区间最值查询 | O(n) | O(log n) | **O(1)** | O(1)（同块 O(B)） |
| 预处理 | — | O(n) | O(n log n) | **O(n)**（块间仅 O((n/B) log)） |
| 单点修改 | O(1) | O(log n) | 不支持 | O(B) 重算块 |
| 空间 | n | 4n | n·log n | ≈3n + (n/B)·log(n/B) |
| 适用场景 | 一次性 | 动态数据 | **静态大量查询** | 静态 + 内存紧张 |

三点效率来源：
1. **重叠拼接（幂等性红利）**：`min` 满足 `min(x,x)=x`，所以 `[l,r]` 可以拆成两段**互相重叠**的
   长度 2^k 区间（k = ⌊log₂(r−l+1)⌋），重叠部分重复计入也不影响结果——这正是 O(1) 查询的根源。
   不可重复贡献的运算（如区间和、区间乘）不能用 ST。
2. **预处理 lg 表**：查询时 `k = lg[r−l+1]` 是查表而非计算 `log2`（浮点 `log2` 单次 ~20ns，查表 ~1ns），
   这是 ST 常数小的关键一环。
3. **分块降空间**：块内前缀/后缀 min（2n 空间）+ 块最小值的迷你 ST（(n/B)·log 空间），
   把 n·log n 压到 ≈3n。代价是同块查询退化到 O(B)，B=64 时扫描开销 ≈ 2ns，几乎无感。

---

## 2. 原理

**预处理**：`st[k][i] = min(a[i..i+2^k))`，由两层递推合并：

```
st[k][i] = min(st[k-1][i], st[k-1][i + 2^(k-1)])
```

**查询 [l, r]**：

```
k = ⌊log₂(r − l + 1)⌋          // 最长的、不超过区间长度的 2 的幂
ans = min( st[k][l], st[k][r − 2^k + 1] )
```

两段区间 `[l, l+2^k)` 与 `[r−2^k+1, r]` 并起来**恰好覆盖** `[l, r]`（可能重叠但不会遗漏）。

**分块 ST**（块大小 B）：

```
pre[i] = min(块首 .. i)        // 块内前缀
suf[i] = min(i .. 块尾)        // 块内后缀
bmin[j] = 第 j 块的最小值 → 再建 ST

查询 [l, r]:
  同块        → 线性扫 a[l..r]           （O(B)）
  相邻两块    → min(suf[l], pre[r])       （O(1)）
  隔中间整块  → min(suf[l], ST(块 bl+1..br−1), pre[r])   （O(1)）
```

## 3. 本程序包含的两个变体

1. `SparseTable`：经典 n·log n 空间 O(1) RMQ，静态区间最小值的最快实现。
2. `BlockST`：分块变体，≈3n 空间、准 O(1) 查询；同块线性扫描保证任意区间都正确。
   基准对比见第 5 节（程序自动运行）。

## 4. 代码要点

- **lg 表开 n+1**：查询长度最大为 n，`lg_.assign(n_+1, 0)`；开 n 会在全区间查询时越界。
- **右端点 `r − 2^k + 1`**：漏掉 `+1` 是 ST 第一大笔误——两段区间会错位，覆盖不全。
- **层数 `LOG = lg[n] + 1`**：n=1 时 lg[1]=0、LOG=1，只有第 0 层，程序已用 n=1 样例覆盖。
- **内存布局**：`vector<vector<int>>` 每层独立分配，访问模式 `st[k][i]` 与 `st[k][i+half]` 相邻，
  缓存友好；极致优化可压平成一维 `st[k*(n+1)+i]`。
- **大值域**：值域无关，min/max/gcd 都行；但聚合值注意溢出（本程序基准用 int 存元素、
  校验和用 uint64 累加防编译器删除查询）。
- **对拍设计**：值域取 [−20,20] 制造大量重复值、块大小随机（覆盖 B=1、残块、n<B 等边界）、
  每轮强制一次全区间查询。

## 5. 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 用 ST 求区间和 | 重叠段被重复计数 | ST 只用于幂等运算（min/max/gcd/and/or） |
| lg 表只开 n | 全区间查询越界 | 开 n+1 |
| `st[k][r−2^k]` 漏 +1 | 覆盖不全，结果偏大 | `st[k][r−2^k+1]` |
| 层数开 `lg[n]` | 最大 k 无对应层 | `LOG = lg[n] + 1` |
| 动态数据用 ST | 修改需 O(n log n) 重建 | 换线段树；或分块单点 O(B) 重算 |
| 分块 ST 末尾残块 suf 断错 | 尾块后缀 min 提前截断 | 块尾条件为 `(i+1)%B==0 ‖ i==n−1` |
| 预处理用浮点 log2 | 查询慢 + 边界舍入风险 | 预计算整型 lg 表 |
