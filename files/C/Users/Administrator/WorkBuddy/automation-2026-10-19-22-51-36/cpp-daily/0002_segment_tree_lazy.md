# 0002 · 线段树 + 懒标记 (Lazy Propagation & Tag Permanence)

> 一句话结论：懒标记让线段树在 **O(log n)** 内完成"区间修改"，把朴素 O(n) 的区间操作降低一个数量级；
> 而在"区间加 + 区间和"这类场景里，**标记永久化**可以进一步砍掉 pushdown 的开销，实测快 1.3~1.8 倍。

---

## 1. 为什么它"高效"

| 维度 | 朴素数组 | 懒标记线段树 | 标记永久化线段树 |
|---|---|---|---|
| 区间修改 | O(n) 逐点改 | **O(log n)** | **O(log n)**，常数更小 |
| 区间查询 | O(n) 逐点加 | O(log n) | O(log n)，无 pushdown |
| 区间赋值 | O(n) | O(log n)（双标记） | 规则复杂，一般不用 |
| 空间 | n | 4n | 4n |
| 建树 | — | O(n) 一次递归 | O(n) |

三点效率来源：
1. **懒标记（deferred work）**：整段覆盖/加法先记在节点上，不真正下传；只有操作深入到子区间时才 `push`。一次区间修改从"碰 n 个叶子"变成"碰 ≤ 4⌈log n⌉ 个节点"。
2. **标记永久化（no push at all）**：途中每个节点把"交集长度 × 增量"即时计入 sum，增量永久留在 `add[node]`；查询时祖先残留标记按交集折算。省掉下传写内存 + 回溯 pull 两趟。
3. **递归区间裁剪**：`l <= mid` / `r > mid` 保证每次只递归一个分支，路径数受控。

---

## 2. 原理：双标记的合并规则

每个节点维护 `sum` 与两个懒标记：

- `cov / val`：整段**先**覆盖为 val（优先级最高）
- `add`：整段**再**加 add（叠加在覆盖之上）

两种标记相遇时的合并（这是正确性的全部）：

```
applyCov(node, v):  sum = v*len;  cov=true; val=v; add=0   // 覆盖吞掉旧加标记
applyAdd(node, d):  sum += d*len
                    if cov: val += d      // 已覆盖 → 加法并入覆盖值
                    else:   add  += d     // 未覆盖 → 正常叠加
```

`push` 顺序：先下发覆盖，再下发加。只要 apply 规则与 push 顺序一致，任意操作序列都正确。

**标记永久化**（仅区间加 + 区间和）：

```
修改: sum[node] += d * |[l,r] ∩ [lo,hi]|   // 途经即累加, 一步到位
      完全覆盖时 add[node] += d            // 增量永久留存
查询: 完全覆盖 → sum[node]
      部分覆盖 → add[node] * |查询∩节点| + 递归子节点
```

代价与边界：永久化要求标记对任意查询可"折算"（可乘交集长度），纯加法满足；覆盖不满足，故混合场景退回 pushdown 版。

---

## 3. 本程序包含的两个变体

1. `SegTreeLazy`：双标记 pushdown 版，支持**区间加 / 区间赋值 / 区间和**，是最通用的模板（洛谷 P3378 类、线段树 2 题型直接可用）。
2. `SegTreePermanent`：标记永久化版，**区间加 + 区间和**，免 pushdown、无 pull 回溯，同为 O(log n) 但每步工作量更少；基准实测见第 5 节。

---

## 4. 代码要点

- 数组开 **4n**：非满二叉时节点编号最大可到 4n−1，开 2n 会越界（这是线段树第一大 UB 来源）。
- `push` 里左右孩子的长度必须分开算：`lenL = mid−lo+1`（向上取整），`lenR = hi−mid`；用 `len/2` 一刀切在偶数长度下刚好对、奇数长度下必错。
- 覆盖标记下传后要**复位** `cov[node]=false`，加标记复位 `add[node]=0`；漏复位 = 标记重复下发。
- `applyCov` 必须清零 `add`：覆盖语义是"从此值重新开始"，残留加标记会造成双重叠加。
- 区间和等聚合信息用 `long long`：n=10⁶、每次加 10⁹，20 万次修改即溢出 int。
- 查询函数应写成 `const` 且无副作用（不真正修改状态）；pushdown 版查询里的 push 是逻辑必需的，若要严格只读可改用永久化版本。

## 5. 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 数组开 2n | 越界 UB / RE | 开 4n |
| push 用 `len/2` 算左孩子长度 | 奇数长度时 sum 错 | `lenL = mid−lo+1, lenR = hi−mid` |
| 覆盖后不清 add | 后续区间加双重生效 | `applyCov` 里 `add=0` |
| push 先加后覆盖 | 标记顺序颠倒结果错 | 先覆盖后加，与 apply 规则一致 |
| 永久化查询漏算祖先标记 | 部分区间结果偏小 | `add * (min(hi,r)−max(lo,l)+1)` |
| 只重算子树不 pull 父节点 | sum 永久失真 | 修改后 `pull(node)` |

## 6. 配套练习

- 洛谷 P3372【模板】线段树 1 —— 区间加 + 区间和（本程序 permanent 版可直接过）

- 洛谷 P2357 守墓人 —— 区间加 + 单点复活 + 区间和

## 7. 运行

```bash
g++ -O2 -std=c++17 -Wall -Wextra -o segtree 0002_segment_tree_lazy.cpp
./segtree
```

程序自动做三组随机对拍（各 200 轮）：覆盖/加/求和混合、永久化版、边界样例（n=1、整段覆盖后立即整段加），
并打印 pushdown 版与标记永久化版的性能对比（n = 2²⁰，每类操作 2¹⁹ 次）。全部通过返回码为 0。

> 通过 3 组共 500 轮、约 48 万次操作的随机对拍（含覆盖后立即区间加、整段操作、n=1 等边界）。
> 源码自带同一套对拍，编译运行即可自校验。
