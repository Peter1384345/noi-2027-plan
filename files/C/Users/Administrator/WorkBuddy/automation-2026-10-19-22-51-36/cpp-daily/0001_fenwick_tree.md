# 0001 · 树状数组 Fenwick Tree

> 一句话结论：在「单点修改 + 前缀和」这一类操作上，树状数组用 **1/4 的内存、约 1/3 的常数** 做到了与线段树相同的 O(log n) 复杂度，是性价比最高的一维数据结构。

---

## 1. 为什么它"高效"

| 维度 | 树状数组 | 线段树（迭代写法） |
|---|---|---|
| 单点修改 | O(log n)，实际约 10 次循环 | O(log n)，固定 20 次循环（2^20 规模） |
| 前缀和 | O(log n)，循环次数 = popcount 级别 | O(log n)，循环次数 = 位宽 |
| 空间 | n+1 个 i64 | 2·2^⌈log n⌉ 个 i64 |
| 建树 | **O(n)** 一次线性扫描 | O(n) 但常数更大 |
| 求第 k 小 | **O(log n)** 倍增二分 | 需 O(log² n) 或在节点存最大值 |
| 可维护信息 | 只有「可减」的运算（和、异或、计数） | 任意可合并信息（max/min/矩阵…） |

三点效率来源：
1. **内存连续**：单个一维数组，无指针跳转，缓存命中率远高于指针式线段树。
2. **位运算定位**：`i += i & -i` 只用一条 `neg` + `and`，分支极少，分支预测友好。
3. **循环次数不确定但更短**：修改时循环次数 = ⌈log₂n⌉ − popcount(i) + 1，平均约 log n / 2。

---

## 2. 原理：lowbit 分层

把下标 i 的二进制最低位 1 拎出来记作 `lowbit(i) = i & -i`。节点 i 管辖区间

```
(i - lowbit(i), i]        长度恰为 lowbit(i)
```

于是：
- `i = 6 (110)`，lowbit = 2，管辖 a[5..6]
- `i = 8 (1000)`，lowbit = 8，管辖 a[1..8]

两条链构成全部操作：
- **修改**：x 变化会影响 i = x, x+lowbit(x), …（向上覆盖它的祖先）
- **查询**：prefix(x) = t[x] + t[x−lowbit(x)] + …（向左下把区间块拼起来）

第 k 小查询则利用「树的每层是一个二进制位」：从最高位开始试填 `pos + 2^p`，若该块前缀和仍小于 k 就整块跳过。**这是树状数组相对线段树最独特的优势。**

---

## 3. 本程序包含的三种"高效变体"

1. `Fenwick`：O(n) 线性建树（`t[i]` 初值放 a[i]，再让子节点累加到父节点 `i + lowbit(i)`），比 n 次 `add` 少一个 log 的常数。
2. `Fenwick::kth(k)`：倍增二分求最小的 idx 使 prefix(idx) ≥ k，单次 O(log n)，用于「按权重随机抽样 / 求第 k 个 1」。
3. `RangeFenwick`：双 BIT 支持 **区间加 + 区间和**。设差分 d[i]，则

   ```
   prefix(x) = (x+1) · Σd[i] − Σ i·d[i]      (i ≤ x)
   ```

   维护 BIT1 = d[i]、BIT2 = i·d[i] 即可，两次 O(log n) 完成区间修改。

---

## 4. 代码要点

- `i & -i` 依赖二进制补码，`int` 与 `long long` 都成立；**下标必须从 1 开始**。
- 求 kth 的循环上界要用 `1 << floor(log2 n)`，不是 `1 << 20`；从最高有效位起试，才是正确的倍增。
- 双 BIT 的右端点标记落在 `r+1`，因此数组要开 `n+2` 位，省去 if 边界判断（本程序就是这么做的）。
- 值域大时开 `long long`：区间加 1e5 次、每次 1e9，和会溢出 int。
- 计数类问题（逆序对）直接拿值当下标，需要先离散化。

## 5. 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 用 0 当下标 | `i & -i == 0` 死循环 | 全部 1-indexed |
| `kth` 用 `<=` 判定 | 返回第一个 > k 的位置 | 用严格 `<`，返回 `pos+1` |
| 建树直接 `for i: add(i, a[i])` | 多一个 log 常数 | 顺推父节点 `j = i + (i&-i)` |
| 双 BIT 忘了 r+1 越界 | UB | 开 n+2 |
| 求区间 max/min | 结果错误 | BIT 只能维护可减信息，改用线段树/ST 表 |
