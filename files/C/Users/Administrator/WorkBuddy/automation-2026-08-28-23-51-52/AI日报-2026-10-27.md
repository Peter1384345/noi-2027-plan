## 1. OpenAI 发布 GPT-6.1 Terra：把 computer use 下放到半价档，Terminal-Bench 4.0 从 21.5% 跳到 50.3%（AI Coding）

**事件**：OpenAI 10/26 发布 GPT-6.1 Terra，定位"视觉理解 + 计算机操作 + 写作 + 日常编程"的中档主力。定价是本次发布的核心信息：输入 $1/百万 token、缓存输入 $0.05、输出 $5，较 GPT-5.6 Terra 与 GPT-6.1 Sol 均低 50%，为旗舰 GPT-6 Astra 的十分之一。上下文 1.05M、最大输出 128K。能力侧，最高推理档的 Terminal-Bench 4.0 任务解决率 **50.3%**，上一代 GPT-5.6 Terra 公开成绩为 21.5%；Terminal-Bench-Science 0.1 上反超定位更高的 GPT-6.1 Sol，距 Claude Opus 5.5 不足 5 个百分点而估算成本低于后者五分之一。Agents' Last Exam 中档覆盖 57.6%、$0.29/任务，前代为 42.6%、$0.84/任务。内部幻觉测试低推理档错误率由 53.6% 降至 16.7%，最高档 4.3%。已在 ChatGPT Work 与 Codex 向 Plus/Pro/Enterprise/Edu 开放（免费与 Business 未开），API 模型名 `gpt-6.1-terra`，Codex CLI 需 ≥0.159.0。

**值得关注的原因**：这条的真正含义不是"又一个模型"，而是**编码 agent 的成本口径从"模型单价"切换成"每成功任务成本"**。$0.29 对 $0.84 的对比说明，即便能力提升有限，只要单位任务成本降到三分之一，多数原本算不过账的自动化流程就会被重新评估——这与同日 The Information 报道的 OpenAI 对 Codex/API 企业客户降价 20%–30%（部分最高 40%）叠加免费额度，构成同一个方向。三个约束需同时记住：其一，**安全定级与能力同源**——Terra 在 OpenAI Preparedness Framework 下被评为网络安全"Critical"级，即"能高效写代码"与"能找到并利用漏洞"是同一能力的两面，而这次是把该能力大幅降价扩容；其二，**计费细节决定实际成本**——区域数据处理加价 10%，prompt 超过 272K token 的输入部分按 2 倍计价，长上下文的 agent 循环会偏离名义单价；其三，OpenAI 明确最复杂软件工程仍应选 Sol 与 Astra，Terra 的定位是"便宜地跑大量循环"，而非"替代旗舰"。全部基准均为厂商自报，尚无独立复测。

**信源**：OpenAI 官方发布及开发者社区（2026-10-26）、36氪、AI Weekly、TechNewsReel、The Information（企业降价，经 AI Times 转述；基准为厂商自报口径）

## 2. 前 GitHub CEO 的 Entire 公开发布：用 agent 打分取代 Pull Request，五次循环后分数稳定才允许合并（AI Coding）

**事件**：Thomas Dohmke 创办的 Entire 10/26 开放其 Git 托管服务，自称"为 agent-human 协作而建的第一個 Git forge"，建立在三个原语上。**Trail** 取代 PR：每次 push 触发多个审查 agent 在云沙箱内独立运行、各自提交分数与理由（默认含 Security、Slop、Human Review Required 三项），页面顶部以"飞行员抬头显示器"式面板展示最近 5 次与当前运行结果，用于判断"编码 agent 与审查 agent 之间的循环是否已收敛到稳定态"；agent 还可返回带严重度的 findings 与修复建议，仓库可开 Gates 要求人工审批与 CI 通过后才能合并。**分布式 Git 托管**：自研 Git 兼容服务，自报 push 吞吐 418 次/秒（GitHub 4.7、GitLab 10、Cursor Origin 65），即"比 GitHub 快 89 倍、比 Cursor Origin 快 6 倍"；已在美国、欧盟、澳大利亚、印度四区上线，可镜像 GitHub 仓库。**Continuous Memory**：`entire-graph`（代码库结构图）+ 与代码同仓存储的会话/prompt 索引 `entire-brain`，均 MIT 开源，自报可省最多 71% token。底层审查 agent 跑 Claude Code 与 Codex 的最新模型，沙箱由 Daytona 与 E2B 提供；CI 首日接入 Buildkite 与 Depot。平台本身免费，只按审查 agent 消耗的 token 计费，附 $100 启动额度。

**值得关注的原因**：Dohmke 对现状的判断值得单独引用——**"Pull Request 已经退化成一个只有 agent 在读的审计日志"**：编码 agent 与审查 agent 互相刷长评论，人类拿不到"是否可以放心合并"的决策信息。Trails 的解法是把判断依据从"读 diff"换成"读分数 + 是否收敛"，并要求**连续多轮分数稳定**而非单轮通过，这直接对应此前量化的行业瓶颈（AI 写码产量远超人类审查容量）。三个待验证项必须标注：其一，**89x/71% 均为厂商自测**，虽已开源基准工具 ForgeMark，但尚无第三方复现；其二，**公开仓库与自托管均未上线**，当前只支持私有仓，团队迁移成本未知；其三，也是最重要的——当"不看代码就合并"成为产品默认路径，**评测集本身的覆盖度就成了新的单点**。用 Security/Slop 三项分数替代逐行阅读，等于把代码质量的最终裁量权交给一组可配置的 eval，而这些 eval 恰好跑在被审查的同一批模型上。这是审查效率的真实跃迁，也是一个新的、尚未被检验的信任假设。

**信源**：Entire 官方博客（Dohmke，2026-10-26）、ZDNet、The New Stack、GeekWire、TSNMedia、AI Parabellum（速度与省 token 数据为厂商自测口径）

## 3. 清华 × NUS 提出 ParallelWorld：机器人动手前先在"平行世界"预演多条未来，位置交换任务成功率 56% → 83%（具身智能）

**事件**：清华大学与新加坡国立大学研究者提出 ParallelWorld（arXiv 2608.22971，代码已开源），把测试时算力用于**行动后果预演**而非一次性推理。系统在高层规划与动作执行之间插入"想象循环"：规划器基于当前观察提出多个候选动作 → 模拟或预测每个动作后的观察，形成搜索树 → 验证器按"信息增益 / 任务推进"给候选分支排序并剪枝 → 选定轨迹后**只执行第一个动作**，再依据执行后的新观察重规划（滚动规划，避免长程预测漂移）。底层控制仍由既有策略完成，搜索只发生在有明确终止条件的高层动作上。在 LIBERO-Pro 的 8 种设置上全部超过 HarnessVLA 基线：Spatial 位置交换 **56%→83%（+27pt）**、Object 指令重定向 79%→94%、Goal 位置交换 57%→66%、LIBERO-10 位置交换 29%→30%。ESI-Bench 在 28 个可测子类中 26 项超过顺序式主动探索，部分遮挡 57.89%→77.89%、未观察到的变化 70.95%→89.86%、镜面反射中的空间关系 36.28%→51.33%。

**值得关注的原因**：这项工作给出了一个对产业更有用的归因——**相当比例的机器人失败并非"手不够巧"或"看不清"，而是"顺序选错了"**，而顺序错误可以在不新增传感器、不重训底层控制的条件下，靠预演消除。同样重要的是论文没有掩盖边界，三组反向证据构成了完整判断：**其一，预演不保证收益**——固定搜索宽度为 2 时成功率 10.0%，反而低于直接执行的 23.3%，作者归因于搜索预算与决策不确定性不匹配，只有自适应宽度才拿到 73.3%；**其二，代价明确**——自适应策略平均耗时 2402 秒，是直接执行 417 秒的约 5.8 倍，且该消融只覆盖 3 个任务，不足以建立算力与性能的普遍规律；**其三，视觉合理性不等于物理可行性**——刚性容纳任务从 60% 降至 50%、几何构型从 17.96% 降至 16.90%，说明当任务成败取决于精确度量与接触动力学时，只看"想象出来的画面"无法替代物理预测。这三条恰好划出了"用推理成本置换执行风险"这条路的当前适用边界：视角选择、目标辨认、空间布局受益最大；精密几何与接触过程仍是盲区。

**信源**：arXiv 2608.22971、项目主页 agenticei.github.io/ParallelWorld-page、github.com/AgenticEI/ParallelWorld、机器之心（2026-10-26）、Hamidun News（arXiv 预印本，未 peer review）

## 4. 智元发布安规级重载机器人精灵 G2 Max：40kg 负载与 ±0.5mm 精度同机，已在自家产线"机器人造机器人"（具身智能）

**事件**：智元 10/26 于 AI WAVE 发布精灵 G2 Max，主攻工业搬运的长期两难——重载设备放料粗糙、精密设备扛不起重量。硬件上单臂负载 20kg、双臂额定 40kg、峰值 50kg，手臂重复定位精度 ≤±0.5mm，7 自由度力控双臂配视觉引导 + 双臂力控，覆盖市面 95% 以上工业料箱与零部件，兼容纸箱、欧标周转箱与异形件，无需大量重新示教标定。空间适配是另一条设计主线：垂直作业区间 0.1–2.5m、水平 1.2m，靠高精度腰部俯仰关节主动前倾实现单面拆码垛，托盘可直接贴墙摆放、省去背后 1.5m 绕行通道。落地数据（厂商与客户口径）：日化快消混线物料识别率 100%，贯通拆垛—开箱上料—盖膜—空箱回收全流程；电商仓储对接"货到人"体系，作业成功率 >99%，拆垛 80 箱/小时、码垛 75 箱/小时；零部件仓库单箱节拍 35 秒、成功率 ≥99.9%。最具标志性的是在沪光股份启元 T1 产线上承担肩关节壳体、髋关节总成的精密搬运，匹配**2.5 分钟下线一台**的节拍，厂长评价"全天候节拍曲线几乎是一条横线"。双电池热插拔 + 自主回充支持 7×24 运行，原生适配上周发布的 Genie Studio 2.0。10/29 智元创新日将做实景展示。

**值得关注的原因**：这条值得记的不是参数，而是它选了一个**自我指涉的验收方式**——让机器人去造机器人。这比任何第三方测试都更严格，因为被搬运的肩关节壳体、髋关节总成是整机精度要求最高的零件，"安装面稍有磕碰就影响关节模组寿命"，而 2.5 分钟的节拍意味着物料供给晚一分钟下游工位就开始干等。三个可迁移的判断：**其一，工业落地的真实门槛是"改造成本"而非"能力上限"**——贴墙摆放、免预留绕行空间、垂直 2.5m 覆盖，这些设计直接对应老厂房不愿推倒重建的现实，比多 10kg 负载更有商业价值；**其二，节拍的稳定性优先于峰值能力**——"曲线是一条直线"是产线唯一认的指标，这与演示视频里的单次成功是两个物种；**其三，具身智能已经开始给自己当供应商**，这是产业链自洽度提升的一个可观测信号。需要标注：所有成功率、识别率、节拍数据均为企业及客户方口径，尚无独立第三方测量。

**信源**：证券时报（2026-10-26）、赛迪网、腾讯新闻、CNMO、智元机器人官方发布（产线数据为企业与客户口径）

## 5. Counterpoint：2030 年人形机器人 AI 加速器累计出货破 100 万台，2026–2030 年复合增速 144%（具身智能 / 算力）

**事件**：Counterpoint Research 10/26 发布《全球人形机器人追踪报告》，预计 2030 年全球人形机器人 AI 加速器累计出货量突破 **100 万台**，2026–2030 年 CAGR 达 **144%**。架构层面，因 VLA 模型与世界模型逐步融合，GPU 短期内仍是人形机器人算力主流；AI ASIC 同步崛起，特斯拉、小鹏等垂直整合厂商正把汽车自研芯片迁移至机器人产品线。厂商格局：英伟达凭"算力芯片 + 模型 + 仿真工具"全栈主导 GPU 细分，合作方含智元、宇树、优必选、银河通用、Figure AI、Neura Robotics、Noetix Robotics；高通以异构计算切入，主打能效与更低 BoM，与 Neura、VinMotion、Booster、Figure 达成设计合作但出货规模差距明显；英特尔存在感最弱；国内地瓜机器人（D-Robotics，地平线分拆）以 RDK S100"CPU+BPU+MCU"套件（Nash 架构 BPU，80 TOPS）与乐聚、LIMX Dynamics 合作。首席分析师 Soumen Mandal 判断算力生态正从 GPU 单极转向多架构共存，随着模型从 VLA 向世界行动模型（WAM）演进，低功耗、小散热、高能效的专用算力价值上升；副总监 Ethan Qi 认为车企将是 ASIC 路线核心推动者，2027 年后 AGI 级加速器量产将使竞争加剧。报告未披露英伟达具体份额百分比。

**值得关注的原因**：这是把具身智能的竞争坐标从"整机出货"移到"机载算力"的第一份系统性预测，也是首次有一个指标把上游芯片与下游产能放在同一张表上对照。需要特别指出的**口径陷阱**：报告说"2030 年累计 100 万台加速器"，而同机构 8 月统计 2026 上半年整机出货已超 2.2 万台（同比近 +300%），工信部 10/19 给出的中国口径是上半年整机产品突破 400 款、产量超 4 万台、全年预计突破 10 万台——**整机按年计、芯片按五年累计计，"同一个一百万"出现在两个完全不同量级的口径里**，混用会得出"芯片严重供不应求"的错误结论。真正有信息量的是三个结构性判断：其一，**算力订单已先于整机产能动起来**，说明上游对量产节奏的预期比整机厂公开口径更乐观；其二，**整机厂在同时接洽 GPU 与 ASIC 两条线**（Figure 同时出现在英伟达与高通名单中），说明架构尚未收敛、供应商锁定尚未形成；其三，**车企的竞争优势在于可迁移资产**（制造经验 + 自研芯片 + 专有模型 + 软硬全栈），这与整车厂的产业位置高度同源，是这一轮格局变化中最值得跟踪的变量。

## 今日主线

今天的五条消息分属两条线，但都在回答同一个问题：**当 agent 或机器人的"动作"变得便宜，谁来承担"验证"的成本？**

- **Coding 侧的关键词是"验证成为产品原语"**。Terra 把单任务成本压到 $0.29，意味着"多跑几轮"不再是奢侈选择，成本不再是不验证的理由；Entire 则在平台层给出制度回应——PR 被换成 eval 分数面板，合并的前提从"人读过 diff"变成"连续多轮分数收敛"。两者合起来说明，编码 agent 的竞争重心已完整移出模型能力：**降价把循环变便宜，平台给循环设止损**。附带的 vLLM 数据把这件事的数学讲得更直白——单步工具调用成功率 95% 时，50 步串行任务的全链成功率只有约 8%，**agent 可靠性是乘法的**，这正是必须靠多轮 eval 而非单点检查的原因。
- **具身侧的关键词是"把试错前移"**。ParallelWorld 在行动之前用 5.8 倍推理时间换 27 个百分点成功率，本质是把试错成本从"真实世界的返工"搬到"想象中的预演"；G2 Max 把重载与精密的工程矛盾收进同一机身，并在自家产线上接受 2.5 分钟节拍的检验——这是把验证成本从"第三方测评"搬到"自我供给的生产关系"里；Counterpoint 则提示验证门槛正从整机下渗到加速器层，竞争开始以"颗"为单位计数。
- **两条线共同的判断变化**：过去一年比的是"能不能做到"，现在比的是"每做到一次要付多少代价、以及错了能不能被及时拦住"。规模不再是护城河，**单位任务的成本与可验证性**才是。
