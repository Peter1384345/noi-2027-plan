## 1. Anthropic 统一 Claude 入口：Cowork 并入主聊天，Docs / Slides / Design 直接进对话

**事件**：Anthropic 宣布把 Claude Cowork 与主聊天合并为单一入口，用户无需先选择「聊天」还是「执行」模式，Claude 自行判断任务需要问答还是长时 agentic 工作；同一对话可直接生成、编辑并导出 Claude Docs（文档）和 Claude Slides（演示），Claude Design 也内嵌到对话中。Pro / Max 用户先行 rollout，Team / Free 随后，企业管理员至少提前 30 天收到通知。

**来源**：Anthropic 官方博客 [Cowork is now Claude](https://claude.com/blog/cowork-is-now-claude)（2026-09-16）

**为什么值得看**：
- 这是「Copilot → 协作者」范式的又一次产品落地：从「多个 AI 工具窗口」切到「一个 Claude 完成聊-写-审-改-演示」的闭环。
- 对 Claude Code 的延伸意义最大：Design / Docs / Slides 未来可直接指向仓库里的 RFC、代码与真实文件，意味着需求文档 → PR → 评审 → 演示稿可能在 Claude 内部串起来。
- 对国内厂商的启示：豆包 / Kimi / 文心等若仍把「聊天」「工作」「代码」分成多个入口，年底可能在用户心智上被拉开一个身位。

## 2. DeepSeek 开源 Harness：插件化 Agent 运行时

**事件**：DeepSeek 发布并开源 MIT 许可的 Agent 运行时 **DeepSeek Harness（dsh）**，核心思想是「一切皆插件」——模型适配器、工具、技能、会话、沙箱、存储、调度、主循环、UI 全部以插件形式挂载到共享服务上下文，支持热插拔与可逆副作用。同日发布配套设计论文。Harness 提供 Standard / Code / Minimal / Creator 四种预设模式，可通过 `npx @deepseek-ai/dsh web` 快速启动。

**来源**：GitHub `deepseek-ai/deepseek-harness`；Studio Global [技术解读](https://www.studioglobal.ai/discover/answers/what-is-deepseek-harness-the-mit-licensed-developer-preview-6aab34594828c0934460c734)（2026-09）

**为什么值得看**：
- 这是国内厂商首次以「插件化调度框架」姿态进入 AI coding 基础设施层，竞争焦点从 prompt 模板/单一模型能力升级到 **runtime 生态**。
- 开发者可以像搭积木一样把多家 coding agent 串成工作流——例如 Claude 写、Codex 审、DeepSeek 自己推理，单家 coding agent 的护城河被进一步压低。
- 需注意其安全记录：OX Security 此前披露 Harness 本地 API 存在 CVE-2026-82533（CVSS 9.4）沙箱逃逸漏洞，DeepSeek 已发布 0.1.2-alpha.1 修复；企业采用时建议优先验证权限模型。

## 3. Anthropic 发布 Model Hardware Standard（MHS）研究预览：AI 代理操作物理设备的通用接口

**事件**：Anthropic 开放 **Model Hardware Standard（MHS）** 研究预览，定位为 LLM 与可编程物理设备（显微镜、液体处理仪、机械臂、激光器、量子计算设备等）之间的通用接口。MHS 用标准化驱动把设备能力抽象为「读/写」原语，设备可被自动发现；安全限制硬编码在驱动层，模型无法绕过。首批合作方包括 AWS、Universal Robots、Doosan Robotics、Danaher、Tecan、QIAGEN、Hugging Face LeRobot、Raspberry Pi 等。Anthropic 计划在建立安全评估后开源。

**来源**：Anthropic 官方 [MHS Research Preview](https://www.anthropic.com/news/model-hardware-standard-research-preview)；WIRED / CNBC / TechCrunch 同步报道；中国经济新闻网 [产业分析](https://www.cet.com.cn/xwsd/10562154.shtml)

**为什么值得看**：
- 这是 MCP（Model Context Protocol）之后的第二步：把 AI 从「读数据」推向「控机器」。一旦 MHS 成为事实标准，实验室/工厂的人形机器人、机械臂、移液工作站会像手机接 USB-C 一样接入大模型。
- 首批验证数据已出现：Carnegie Mellon 用 MHS 对接 4 台互不兼容设备约 8 小时完成驱动与编排；QuEra 量子计算机激光锁定恢复成功率 99.3%。
- 对国内具身厂商：珞石、智元、宇树等应尽早评估兼容 MCP / MHS 的开放接口，否则在「AI 操作设备」这条新战线上可能被动接受国外协议定义。

## 4. 地瓜机器人完成 4 亿美元 C 轮融资：旭日芯片出货突破 800 万片

**事件**：9 月 17 日，地平线孵化的**地瓜机器人（D-Robotics）**宣布完成 4 亿美元 C 轮融资，由未来资产（Mirae Asset）领投，美团战略投资，合肥国投、南山战新投、璟泉资本等政府平台，以及凯辉、高瓴创投、五源资本、线性资本、淡马锡 Vertex Growth、云锋基金等老股东加码。资金用于完善旭日芯片多算力等级产品矩阵，搭建贯通数据采集、模型训练、仿真验证、推理部署的全链路软件平台。公司同步披露：2026 上半年营收同比数倍增长，旭日系列芯片累计出货突破 800 万片，具身智能客户覆盖率突破 50%，S600 已获它石智航、千寻智能、自变量机器人、优必选、北京人形机器人创新中心等 20 余家头部客户采用。

**来源**：上海证券报·[中国证券网](https://www.cnstock.com/commonDetail/791525?commTag=true)；[证券时报网](https://www.stcn.com/article/detail/4188576.html)；[新京报](https://m.bjnews.com.cn/detail/1789611226129931.html)；[每日经济新闻](https://www.163.com/dy/article/L719KR1V0512B07B.html)

**为什么值得看**：
- 这是 2026 年具身智能领域最大单笔融资之一，资本正在把估值重心从「本体整机」转向「软硬一体基础设施」——芯片 + 工具链 + 数据平台。
- 800 万片出货和 50% 客户覆盖率表明：具身智能的底层算力平台已进入量产验证期，不再是样机阶段。
- 美团战投 + 合肥/南山等地方政府平台入局，说明产业资本与地方国资都把机器人算力底座当作下一个必争基础设施。

## 5. Agility Robotics 发布 Digit 5：首款无围栏人形机器人，已获超 3 亿美元订单

**事件**：9 月 15 日，Agility Robotics 正式发布第五代通用人形机器人 **Digit 5**，主打「cooperatively safe」——可在没有物理安全围栏的情况下与人近距离协同作业。Digit 5 身高 1.81 米、重 129 kg、最大负载 22.7 kg（较上一代提升 40%）、伸展高度 2.2 米；电池续航 90 分钟，快充仅需 9 分钟，24 小时内有效作业可超 20 小时；末端采用 ISO 标准法兰，可快速更换夹爪。安全架构采用多传感器感知 + 独立安全控制器，人员靠近时自主减速、改道或降低姿态坐地断电。Agility 透露 Digit 5 已获得超 3 亿美元多年期订单，2027 年上半年启动早期交付，年底规模化商用，并计划进入欧盟与英国市场。

**来源**：Agility Robotics 官方发布；[中国机器人网](https://www.robot-china.com/news/202609/17/96735.html)；[The Conveyor 分析](https://www.theconveyor.co/p/agility-digit-5-humanoid-safety-cages)（援引 SEC 文件与 TechRepublic）

**为什么值得看**：
- 「无围栏」是工业场景中人形机器人规模化落地的硬门槛：传统工业机器人必须把人与机器物理隔离，牺牲空间效率；Digit 5 的独立安全控制器 + 主控冗余设计是首个为「与人共享空间」重新设计的工业级人形。
- 3 亿美元订单说明客户买的不是 demo，而是可进入仓库/工厂现有布局、无需大规模改造场地的柔性生产力。
- 对国内厂商的启示：人形机器人进工厂的竞争焦点正在从自由度、跑跳 demo 转向**安全架构、连续作业可靠性、投资回报周期**。

## 今日关键洞察：从「能不能做」到「能不能共处于真实空间」

今天两条主线出现同一个拐点：**AI coding 在收敛入口，具身智能在收敛安全边界**。

- **Coding 侧**：Anthropic 把聊天、Cowork、Design、Docs、Slides 压进一个入口，DeepSeek 用 Harness 把不同模型/工具/沙箱做成可插拔 runtime——行业竞争从「模型谁更强」转向「入口是否统一、工作流是否可编排」。
- **具身侧**：MHS 让 AI 能调用物理设备，地瓜 4 亿美元融资让具身算力底座规模化，Digit 5 拆掉围栏让人形机器人真正进入人机共享空间——行业竞争从「本体能不能动」转向「能不能安全地与人共处、能不能持续产生数据并自我改进」。
- **交叉信号**：MHS + Digit 5 的组合意味着，未来工厂里可能同时出现「大模型通过统一协议调度机械臂/检测设备」和「人形机器人无围栏与人协同」的混合形态；标准和安全架构将先于爆款应用决定行业格局。
