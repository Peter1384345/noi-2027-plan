## 1. Anthropic 发布 Claude Haiku 5.5：小模型价格再降 90%，agent 基准脱胎换骨

**事件**：Anthropic 完成 5.5 世代三款模型布局。Haiku 5.5 在 100K token 以下输入价格仅 $0.10/百万 token（Haiku 4.5 的十分之一），输出 $0.50；1M 上下文；Terminal-Bench 4.0 从 0.0% 升至 39.2%，OSWorld 2.1 从 15.7% 升至 72.4%（厂商自报口径）。同日 Sonnet 5.5 缓存读取价格从 $0.20 降至 $0.10。

**为何值得关注**：coding agent 的成本结构由子代理/小模型承担大部分调用量，Haiku 5.5 把这条路径的成本砍掉一个数量级，等价于把"多 agent 并行"从预算约束中解放出来。注意迁移有坑：自适应思考默认开启，temperature/prefill/budget_tokens 旧设置会直接报 400。

## 2. Claude Code 2.1.304：无人值守 agent 的"人工审批层"产品化

**事件**：新版本加入 /auto-mode-setup 引导式配置（读取项目与历史会话，让 auto mode 理解用户环境）；新增 /claude-api managed-agents-secure 安全自检命令；工具权限系统引入 `decider: "person"`（仅人类/宿主回调可批准）与 `e.isReadOnly` 标记；Code Review 支持组织级全仓库强制审查。

**为何值得关注**：继上周 hooks fail-closed 之后，Anthropic 继续把"人何时必须在场"做成显式 API 而非隐式惯例。无人值守 agent 的治理粒度正在从"全放/全收"进化到"按动作分级审批"，这会直接影响企业采购 coding agent 的合规门槛。

## 3. 奇瑞墨甲首款家庭陪伴人形机器人"墨宝"今日全球首发并开启预订

**事件**：10 月 21 日于安徽芜湖发布，面向家庭消费场景，主打语言交互、视觉识物、日程提醒、长时记忆等陪伴能力，搭载自研 MoAgent 大脑；同步开启全球预订。此前墨甲已在商用接待、智慧交通、医疗导诊等场景探索，本次依托"车机协同"把智能座舱/智驾的感知交互能力平移到机器人。

**为何值得关注**：继小鹏（产线）、特斯拉 Optimus（工厂）之后，奇瑞代表的车企路线明确延伸到"家庭 C 端 + 情感陪伴"，与宇树/智元的通用路线形成分野。汽车供应链 + 制造质量体系能否在消费级家庭场景复制，是四季度具身 C 端最值得跟踪的样本。

## 4. 杭州"世界模型"创业潮：磐虎智能 3 个月拿数千万天使轮，格物通智近亿元

**事件**：浙大系孵化、7 月才注册的磐虎智能宣布完成数千万元天使轮（普华资本、恒择资本），主攻 TigerMind 多维感官认知世界模型；10 月中旬，8 月成立的格物通智完成近亿元天使轮，提出"物理反演世界模型"（从视频反推接触力等隐含物理信息用于预训练）。同期魔芯科技、原力无限、至简动力等杭州公司融资密集。

**为何值得关注**：具身智能的竞争焦点正从"本体性能"转向"智能能力"，世界模型/物理常识成为新估值锚点。杭州模式的特点是浙大系+阿里系人才网 + 极快融资节奏——3 个月公司拿钱说明资本对该赛道的定价已先于产品验证，需警惕重复此前"表演经济"的估值透支风险。

## 5. 南京具身智能大会：算力国标启动编制、全国首个机器人焊接训练场揭幕

**事件**：10 月 20-21 日在南京江北新区举行，宇树、科大讯飞、集萃智造等联合数百所高校成立全国具身智能机器人产教融合联盟；国家电标院华东分院牵头启动《具身智能算力国家标准》编制；全国首个具身智能机器人焊接训练场揭幕，面向真实焊接场景做多模态数据采集。同期大湾区具身智能产业大会（10/21-23，广州）开幕，500+ 参展企业、3 万㎡。

**为何值得关注**：大会主题直指"表演式演示泛滥"——标准编制、真实工业场景训练场、订单式人才培养，三条线都在把行业从 demo 拉回产业。算力国标若落地，将是继数据质量标准之后第二块制度化拼图。
