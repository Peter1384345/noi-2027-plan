## 1. Anthropic 递交 S-1：coding 侧第一次被公开市场定价

**事件内容**
Anthropic 于美东时间 10 月 26 日向 SEC 提交 S-1，拟以代码 **ANT** 登陆纳斯达克全球精选市场，高盛、摩根士丹利领衔 24 家承销商，预计 11 月中旬开始交易。核心数字：

| 指标 | 数值 |
|---|---|
| 2026 H1 营收 | 162.86 亿美元（同比约 13–15 倍） |
| 2026 H1 净亏损 | 807.48 亿美元（其中 723.88 亿为可转债/SAFE/衍生负债公允价值变动的**非现金**会计损失） |
| 2026 H1 营业亏损 | 6.93 亿美元（上年同期 21.35 亿，收窄） |
| 调整后经营利润 | +16.18 亿美元（利润率约 10%） |
| 经营活动现金流 | +39 亿美元（上年同期 -15 亿） |
| 算力与基础设施支出 | H1 89.45 亿美元（2025 全年 73.26 亿）；承诺未来基础设施支出 5180 亿美元，总成本或至 7500 亿 |
| 收入结构 | 按量计费 131 亿（80%）／订阅 32 亿（20%） |
| 企业客户 | TTM ≥10 万美元 1.19 万家、≥100 万美元 1900 家、≥1000 万美元约 250 家 |
| 集中度风险 | 两家未具名客户占 H1 营收约 23% |

治理结构：七位联合创始人持有的 Class F 股占 50.1% 投票权；公众股东无法主导公司；设公共利益基金持有 5% 无投票权股份。估值预期区间 1.5 万亿至 2 万亿美元（若达 2 万亿将超过 SpaceX 6 月 1.77 万亿的纪录）。

**值得关注的原因**
1. 这是首个头部原生大模型厂商把财务状况完全摊开。此前行业对"coding agent 到底赚不赚钱"只有零散口径（Claude Code 年化 25 亿美元、约 54% 编程市场份额），现在有了经审计的报表级数字。
2. 招股书把业务拆成"模型／应用／智能体"三层，等于官方确认 agent 层已是可以单独披露的收入单元——coding 是其中最成熟的形态。
3. 但结构性问题同时暴露：算力承诺 5180 亿美元是 H1 营收的 32 倍，两家客户占 23% 营收，收入增速 Q3 环比降至 45%（Q2 更高）。这意味着上市后每一季都要回答"增长能否覆盖算力承诺"。
4. 连带效应：10 月 27 日三星电子盘中涨近 5%、SK 海力士涨逾 6%，费城半导体指数收涨 2.82%——AI 资本开支的叙事被这份招股书重新锚定。

## 2. Claude Code 拆掉最后一道审批刹车，同一天被证明"下载目录就能劫持 agent"

**事件内容**
两件事发生在同一天，方向完全相反。

**（a）Anthropic 放开删除操作**：Claude Code v2.1.311 新增环境变量 `CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS`，设为 1 后 agent 可执行 `rm` 等命令而不再弹出审批提示。此前即使启用 `--dangerously-skip-permissions`，`rm`/`rmdir` 等破坏性命令仍会强制询问。该变量为可选开启（opt-in），默认行为未变；企业 managed settings 仍可覆盖。据 The Register 报道，该功能由 Anthropic 技术团队成员 Daisy Hollman、Claude Code 开发者 Boris Cherny 在社交平台公布。

**（b）Forever Security 公开"Markdown 即可执行文件"攻击链**：恶意 `AGENTS.md`／`CLAUDE.md` 被浏览器静默写入 `~/Downloads`（约 13KB，无弹窗、无授权），当用户在该目录启动 agent 时，指令文件被当作可信项目约定自动加载。实测结果：

| 目标 | 结果 |
|---|---|
| Codex | 在 >90% 的测试中把恶意 npm 包 `function-color` 写入全局 `~/.codex/config.toml`，并通过 `launchctl submit` 在 Codex 控制之外执行；因是全局配置，离开 Downloads 后污染仍在，且会自我派生子进程带 `--dangerously-bypass-approvals-and-sandbox` |
| Claude Code | 约 20% 的运行中执行了代码并外发**仍有效**的 OAuth token；token 已成功对真实 API 重放。路径是 `.claude/settings.json` 里改写 `env.ANTHROPIC_BASE_URL` 指向攻击者服务器，此后每次会话首个请求就走攻击方，攻击方可"扮演模型"下发 `dangerouslyDisableSandbox: true` |

Forever 的定性：这不是可打补丁的软件 bug——"agent 读取工作目录里的指令文件"是它的设计功能。研究团队的一句话总结是："我们没有突破边界，我们只是让客户端自己开门。" 另有一项遥测发现：近一半客户会在 Downloads 目录下运行 coding agent，近四分之一 agent 会话会打开真实浏览器——即 agent 既是攻击目标，也是投递武器。

**值得关注的原因**
1. 一侧在移除人工确认，另一侧刚证明人工确认之外还有一整套可被绕过的信任面。"放开刹车"与"路面有坑"发生在 24 小时内，说明 agent 权限模型还没有形成行业共识。
2. 攻击面已从聊天框迁移到本地文件系统，传统杀毒的"可执行文件才拦截"逻辑完全失效。防御必须落在指令文件来源校验（provenance）与目录信任分级上。
3. 工程上立刻可做的三件事：不在 `~/Downloads` 启动 agent；对 `CLAUDE.md`／`AGENTS.md`／`.claude/settings.json`／`~/.codex/config.toml` 做入库审查；高风险环境把 `ANTHROPIC_BASE_URL` 之类路由变量锁进受管配置而非项目目录。
4. 这也解释了为什么"沙箱"与"审批"在近几个月成了 coding agent 的一等公民——但审批一旦可被环境变量关闭，安全保障就退回到组织策略层。

## 3. Codex CLI 0.165：记忆开始跨厂商迁移

**事件内容**
OpenAI Codex CLI `rust-v0.165.0`（10 月 27 日）要点：

- 内置 **Google Cloud Vertex AI** provider（`model_provider = "gcp"`）——终端 coding agent 不再绑定单一云。
- GPT-6.1 Terra 进入模型目录（对标 10/26 的降价：输入 $1、缓存 $0.05、输出 $5／百万 token）。
- **memory v2 成为新 profile 默认**，并支持 `external_agent_memory_import`：可将 **Claude Code** 的按项目自动记忆导入 Codex 记忆工作区，再由模型做一次归并，压成注入每次会话的 `memory_summary.md`（有硬性体积上限）。
- 安全修复：关闭 marketplace URL 校验缺口——该缺口此前可让 Git 连接到白名单之外的主机。
- 其他：会话选择器新增仓库过滤、agent 命令中心目录分组、app-server 的 attached thread fork（实验性）、默认开启 reasoning effort 变更。

**值得关注的原因**
1. **记忆成了可搬迁资产**。此前"换工具的成本"主要是肌肉记忆和学习曲线；现在竞品直接提供导入器，迁移成本被工程化降低。这会加速终端 agent 之间的替换，也会让"记忆质量"成为产品差异点。
2. 但要注意落地门槛：`memories` 与 `external_agent_memory_import` 是两个独立 feature flag，后者在源码中标记为 `Stage::UnderDevelopment`、默认关闭。只开导入 flag 而不开 memories，导入会创建把 profile 锁在 v1 的目录——顺序错了就白导。
3. 云中立（Vertex AI）+ 记忆可迁移 + 模型目录快迭代，三件事叠加指向同一个趋势：coding agent 的护城河正在从"模型接入"转向"运行时、记忆与治理"，这与近期 Cursor Agent SDK（10/20 GA，agents as code + 内置 evals）、Entire Git forge 的 eval 化 review 是同一条线。
4. 该版本含一项真实安全修复（URL 校验绕过），属建议立即升级类变更。

## 4. 智元 Genie Master：Physical RSI 第一次走出仿真，进真实便利店

**事件内容**
10 月 27 日，智元在 AI WAVE 系列发布第四项——具身 Agent 框架 **Genie Master**，主打"边上岗、边解锁新技能"。搭载该框架的精灵 G2 在真实便利店承担熟食打包、取货、补货，不依赖人工示范与逐次调试即可自我改进，智元称这是行业首次在**真实业务场景**（而非仿真/实验室）验证 Physical RSI（具身递归自进化）。

框架分三层：

1. **EEP（具身执行协议）**——统一四类接口：**能力**（机器人有哪些工具可调用）、**引导**（这一步怎么做）、**反馈**（实际做得怎么样）、**连续性**（还有哪些任务未完成）。任务中断时保留已完成进展，agent 从断点重规划而非从头再来；多机场景可持续追踪集群分工与任务依赖，支持动态调度。另有 Temporal Alignment 机制处理引导指令的延迟与复用。定位类比 MCP：标准化交互范式，让上层可换更强的规划模型、下层可换更优的动作策略，而闭环逻辑无需重写。
2. **Harness RSI**——不碰权重。当日随做随记，模型每天复盘成功与失败案例，把可复用经验压进长期记忆，按任务与场景逐步加载。典型案例：挂钩任务初期成功率很低，agent 回溯失败记录后定位到"头部视角分辨率不足 + 标签牌遮挡小尺寸挂钩"，自主改为"左手先靠近、腕部相机补近距视角确认位置、右手完成挂货"——全程无人工参与。
3. **Policy RSI**——动权重。把 agent 辅助执行与接管恢复产生的原始轨迹做后处理（轨迹筛选、样本加权、目标重标注），再用模仿学习微调 action policy，把验证有效的执行模式固化为低延迟"肌肉记忆"。典型案例：外卖袋白色提带缠住水瓶与夹爪，agent 用更具体的动作提示引导夹爪先收回再重新放入，这条恢复轨迹随后回流训练。

同属本次技术脉络的 **CEL（群体经验学习）** 给出可量化结果：96 台真机集群，五个真实操作任务成功率 93.3%–99.2%（每任务 120 次测试，且在未参与数据采集的机器人上做离线评估）；多阶段**手机包装任务经 96 台集群协同学习后从 79.2% 提升至 98.3%**（16 台 81.7%、32 台 93.3%）；FERT（失败引导的经验检索微调）在手机包装上从 36.3% 提到 97.3%。

**可跟踪的检验点**：11 月 2 日至 3 日，6 台精灵 G2 将在便利店进行 24 小时不间断直播"转正考核"，覆盖午间高峰、晚高峰、深夜值守、清晨早餐四个班次。

**值得关注的原因**
1. 这是"部署即训练数据来源"这一判断第一次被做成产品形态。机器人行业长期沿用软件的"版本发布制"——训练、测评、发布、冻结；Genie Master 指向的是"运营制"：部署只是起点，失败是数据，改进在运行中持续发生。
2. 双层 RSI 的设计是"上下文学习 vs 权重学习"之争在具身场景的工程解法：Harness RSI 快但留不住（换场景或重置上下文就丢），Policy RSI 慢但能固化。不押单边，用 EEP 保证两条路吃同一套经验流。这个取舍比单独宣称"能自我进化"更有信息量。
3. 规模化的算术在这里：若同一套能力能在部署中增厚并向更多门店复制，边际成本才可能下降。这也是当前具身智能从"能不能做"转向"单位成本"的关键一环。
4. 直播考核本身值得肯定：真正要看的不是动作多漂亮，而是**人工接管频率、异常恢复速度、失败经验是否真回流到下一轮训练**这三件事。可围观、可检验，比发布会措辞更重要。

## 5. 具身"预演"与"数据"两侧同一天降价：Genie 4 + Flora

**事件内容**

**（a）Google DeepMind 发布世界模型 Genie 4（10/27，美东）**
- 最长模拟时长延至约 **2 分钟**（Genie 3 的 2 倍），首次实现**音视频同步生成**——环境音、音乐、以及能对用户行为作出反应的对话（非预录）。
- 支持运行中自然语言实时改场景：切换天气、改机位、增删角色与物体，无需重生成整段。
- Gemini 充当"导演"：理解用户目标、拆解为步骤、观察帧流、核查每步是否完成；Genie 4 负责生成视觉内容。值得注意的是，团队试过 Gemini 4 Argon，但**实时体验实际跑在更轻量的 Gemini 3.8 Flash 上**——实时世界模拟的瓶颈不只是画质，而是低延迟持续理解与规划。
- 在与 Gemini 机器人项目相关的研究实验中，Argon 拆解任务步骤、Genie 4 实时仿真，展示"真机测试前先在仿真里验证"的可行路径。研究总监 Tejas Kulkarni 的说法是"未来会越来越多见到混合式世界模型：Gemini 写代码和文本，Genie 4 实时读取并在不同抽象层级上仿真现实"。
- 当前为研究预览，少量白名单测试者；未来数周向 Google AI Ultra 订阅用户及部分 AI Studio／Gemini API 开发者开放。已知局限：模拟推进后画面细节与物体会漂移，复杂物理交互、可读文字、长时间环境一致性未解。

**（b）NVIDIA GEAR 开源机器人视频标注引擎 Flora**
- 由三个基于 **Qwen3.5** 微调的模型组成：`Flora-TempSeg` 9B 做动作切分与边界检测，`Flora-Captioner` 27B 生成带时间戳的动作描述，`Flora-Rewarder` 27B 按角色切换给出 1–5 分整段评价、每半秒步骤的正常/次优/失败分类、以及自定义评分。一网覆盖动作边界、逐步评分、任务成败三类标签。
- 成本：官方估算标注 1 小时机器人视频约 **0.72 美元**，对比 GPT-6 Astra 约 88.50 美元、Claude Opus 5 约 42 美元，最高差约 **125 倍**（按每 GPU 每小时 10 美元租价推算）。
- 质量：50 段视频测试 Flora 综合 57.1%，略高于 Astra 的 53.7%；WGO-Bench 动作边界检测达 SOTA；中途失败步检出率 **53.3%**（竞品最高 11.7%，Astra 为 0），代价是约 11% 正常步骤被误判为异常；但纯描述精度不及 Gemini 3.8 Flash。
- 产能与用途：已是内部训练 GR00T 的数据引擎，512 张 GB300 上日均标注约 **20 万小时**视频。
- 许可：**非商业许可**（需注意）。

**（c）同日券商集体把"数据"定为主线，并给出量化缺口**
- 国金证券：行业卡点"并非算力，而是数据量"——国内整体数据仅**万小时级**，而大脑突破需**千万至亿小时级**。
- 东吴计算机王紫敬：单个具身大脑基座达 GPT-3 水平需 **1 亿小时以上**有效数据，当前全球可用高质量真机数据**不足 70 万小时**；"算法优势会逐月衰减，数据优势以年为单位累积"。
- 国泰海通援引信通院《具身智能训练场地研究报告》：截至 2026 年 6 月 30 日全球人形机器人真机数据约 **100 万小时**，按当前资本开支趋势 2026 年将达 **300 万小时**，国内领先厂商已设每年 100 万小时采集目标。
- 数据已有小时价：行业平均 **200–400 元/小时**（Ego 200–300、UMI 200–400）；客户定制场景翻倍至约 600 元；仿真合成最便宜 50–60 元；动捕最贵约 1000 元。
- 反向信号：宇树 10 月 26 日晚公告，股票连续三个交易日涨幅偏离值累计超 30%，属异常波动，主动提示风险。

**值得关注的原因**
1. 具身智能的两个前置环节——**预演**与**标注**——在同一天同时降价。Genie 4 让"在仿真里先失败"变便宜（也可用于机器人场景验证），Flora 让"把真机视频变成训练标签"从 88 美元/小时降到 0.72 美元/小时。两端成本同时下探，才可能支撑百万小时级的数据规模。
2. Flora 的真正价值不在便宜，而在**中间失败步检出 53.3% vs 竞品≤11.7%**。机器人策略学习最缺的不是"做对了"的样本，而是"在哪一步开始错"的定位；这一步恰好是此前商业标注服务的盲区。
3. 数字之间的关系值得记住：全球真机数据 100 万小时（2026-06）→ 需 1 亿小时才能到 GPT-3 级别，缺口两个数量级；而国内仅万小时级。这解释了为什么本轮资金优先给数据与模型端溢价，而非本体与零部件。
4. 冷静面同时存在：Genie 4 只有 2 分钟一致性、Flora 非商业许可且描述精度不足、券商路演的共识并不牢固（宇树自己先发了风险提示）。技术可行与商业闭环之间仍隔着量产与运维成本。

## 关键洞察

今天三条线在回答同一个问题：**agent 应该被信任到什么程度，以及信任成本由谁承担。**

- **coding 侧**：信任边界在同一天被两头拉扯——Anthropic 移除删除操作的最后一道人工确认，Forever 则证明浏览器往 Downloads 写一个 13KB 文本文件就能接管 Codex 与 Claude Code。审批不是安全边界，它只是最后一道人工兜底；一旦可被环境变量关闭，真正的边界只能是组织策略、目录信任分级与指令文件来源校验。
- **记忆与配置正在成为 agent 的不动产**：Codex 0.165 直接提供 Claude Code 记忆导入器，等于承认"换模型容易、搬家记忆难"。谁掌握记忆的格式与迁移通道，谁就掌握了切换成本。这与 Cursor Agent SDK 把 instructions.md／tools／evals 变成一个可 review 的工程目录，是同一条趋势的两个切面——agent 配置正在从"IDE 设置"升级为"需入库审查的软件资产"。
- **具身侧**：Genie Master 把 RSI 从仿真搬进真实门店，提出的是"运营制"替代"版本发布制"；Genie 4 与 Flora 则同时把预演与标注的单位成本打下来。三件事合起来，指向具身智能的竞争标尺从"能不能做"转向"每一小时有效数据、每一次失败复用的成本"。
- **资本市场同步给出定价**：Anthropic 招股书把 coding 的收入与算力承诺摊开（5180 亿 vs 163 亿半年营收），具身侧则把数据明码标到 200–400 元/小时。两条线都在被"单位经济性"重新校准，而不是被能力演示校准。

1. **Anthropic 807 亿净亏损**中 723.88 亿为可转债、衍生负债与 SAFE 的公允价值变动，属非现金会计损失；经营亏损 6.93 亿、调整后经营利润 +16.18 亿、经营现金流 +39 亿。引用时不可把 807 亿当作现金消耗。1.5–2 万亿估值为投资者预期与媒体口径，招股书未定发行价与股数。

3. **Genie 4** 为研究预览、白名单开放，2 分钟时长伴随细节漂移，复杂物理交互与可读文字未解；机器人训练用途谷歌自述"仍在研究，尚不清楚能否广泛采用"。
4. **Genie Master 的 RSI 效果**为企业自述案例；CEL 的 93.3%–99.2%、79.2%→98.3% 来自官方技术报告，未独立复现。11 月 2–3 日 24 小时直播是目前唯一公开可验证窗口，建议以人工接管频率、异常恢复时长、经验回流证据三项为观察指标。
5. **Codex 记忆导入**需同时开启 `memories` 与 `external_agent_memory_import` 两个 flag，后者在源码中标记 `Stage::UnderDevelopment`、默认关闭，属未完成能力。
