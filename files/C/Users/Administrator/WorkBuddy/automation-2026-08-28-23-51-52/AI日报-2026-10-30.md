## 1. 谷歌停用 AI 编程助手 Jules：异步 agent 的先行者并入 Antigravity

**事件内容**
谷歌 10 月 29 日宣布逐步停用其 AI 编程助手 Jules（2024 年 12 月推出，定位"完成你不想做的编程工作"，2025 年 8 月 GA）：

- **11 月 11 日**：Jules 切换为只读模式，agent 停止执行任务；
- **12 月 31 日**：完全关闭，此前用户可导出数据与设置；
- 经验（尤其是后台异步任务执行能力）将并入 **Antigravity**——Google DeepMind 2025 年 11 月推出的"智能体优先"开发平台（VS Code 分支独立 IDE，2026 年 I/O 升级 2.0，已支持多 agent 编排、桌面管理与定时任务）。
- 值得注意的缺口：Jules 免费层（每日 15 个任务、3 个并发）在 Antigravity 中没有宣布对应方案。

**值得关注的原因**
1. 这是大厂 coding agent 产品线第一次出现"先烈"级关停：Jules 是最早验证异步 agent（连 GitHub 仓库、云端 VM 里自己干活）的产品之一，不到两年即让位——独立异步 agent 工具正在被"平台化 IDE"吞并，coding agent 竞争进入收敛期。
2. 与昨日 Android Studio BYOA（ACP 开放 40+ 外部 agent）连起来看，Google 的双轨策略已经清晰：能力入口收拢到 Antigravity，标准接口开放给别人——"自有平台 + 开放协议"替代"单品工具"。
3. 对用户是直接的成本信号：免费/低价异步 agent 档位正在消失，agent 用量的免费午餐时代在退潮（与 OpenAI 同日砍又撤回 Pro 额度互为映照）。

## 2. OpenAI 撤回 Pro 额度削减方案，Codex 与 ChatGPT Work 用量上限翻倍

**事件内容**
10 月 30 日凌晨，OpenAI Codex 负责人 Thibault Sottiaux（Tibo）宣布：

- **取消** 9 月 29 日邮件预告的 Pro 200 套餐额度下调方案；此前因过渡期保留高额度的老用户直接维持，适用低额度的用户同步补齐对齐；
- **100 美元与 500 美元 Pro 套餐**，以及 **Business Premium** 的 ChatGPT Work 与 Codex 用量上限**翻倍**，即时生效（无需等计费周期）；
- Plus（20 美元）额度不变；Work 与 Codex 后台共用同一份额度；Fast 模式消耗额度速度为 Standard 模式的 2.5 倍。

**值得关注的原因**
1. 一次罕见的市场信号回撤：用户反弹让 OpenAI 收回了减配计划，说明 agent 用量已成为订阅产品的核心价值锚——"额度"就是 coding agent 的定价单位，用量即留存。
2. 额度翻倍出现在训练/推理成本下降（MoE、缓存、蒸馏）与竞争加剧（Anthropic Haiku 5.5 降价 90%、GPT-6.1 Terra 降价 50%）的交叉点上，供给侧价格战从 API 蔓延到订阅制。
3. 对买方的启示：按席位订阅 agent 的企业现在应把"额度倍数"写进续约谈判——供给过剩期是用锁价换额度的窗口。

## 3. Replit 发布 ViBench 2.0：顶级 coding agent 从零构建完整产品，通过率仅 49%–65%

**事件内容**
Replit 10 月 29 日（美东）发布全产品级编程基准 ViBench 2.0：17 个产品、241 条功能请求、544 份测试计划。

- 与传统 bug 修复基准相反，agent **从空项目起步**，分阶段构建产品，再接收最多 18 个后续功能请求——每个请求都依赖早期代码仍然成立，而 agent 看不到完整路线图；
- 测试以 Uber、GitHub、Google Docs 类产品为模板，早期 schema/路由/部署决策会约束后续所有改动；
- **最难的规则是干净部署**：测试在空数据库上启动，依赖本地残留状态的构建直接判负；
- 8 个产品公开在 GitHub、9 个隐藏，抑制刷榜；全部结果可基于 v2.0.6 在 OpenHands harness 上复跑；
- 结果：顶级 coding agent 通过率 **49%–65%**。

**值得关注的原因**
1. 把"能修 bug"与"能交付产品"的差距第一次做成可复现的量化基准——此前该论断只有横向参照（10 月 1 日 InfoQ 的审查瓶颈、Voss 的 +741% 产量 vs +30% 交付），ViBench 2.0 给出了同口径下的具体数字：长时程产品构建连顶级 agent 也过不了一半。
2. "干净部署 + 后见请求"设计直击 agent 真实失败模式：不是语法错误，而是早期架构选择把后续功能堵死——这正是企业买家最担心的"demo 能跑、生产会塌"。
3. 可复现性被明示为竞争点（公开 harness、隐藏集），直接回应厂商"私有设置刷高分"的行业积习。可跟踪检验点：未来数周 Codex/Cursor/Claude 系是否跟进发布长程基准或提交 ViBench 2.0 成绩。

## 4. 智元创新日：GO-3 Preview 具身基座模型 + "Worken" 机器人能效单位，上半年交付 9700 台

**事件内容**
智元 10 月 29 日上海创新日（10 月 30 日国内媒体集中报道）发布与披露：

- **GO-3 Preview**：新一代具身智能基座模型，公司称是目前行业发布参数量最大的具身模型；据联席总裁姚卯青披露的自报评测，在 RoboDojo、RoboTwin、RoboColiseum 三个评测榜登顶；
- **Worken**（Work + Token）：提出机器人"能效单位"，从数量、工时、产出效能维度量化机器人实际生产力，为具身智能定价与规模化落地提供度量标准；
- **AHA3 硬件平台**、全模态交互模型 WITA-Omni、工业机器人 G2 Max 正式发布（21 自由度、双臂负载 40kg、工作高度 0.1–2.5m）；Link-U OS 1.0 上线；
- **业绩口径**：2026 上半年人形机器人交付 9700 台，占全球市场份额超 43%，营收接近 20 亿元（未披露盈利）；彭志辉：研发团队 30% 投本体、70% 投"智能大脑"；"我们完全有能力一年造几万台，瓶颈是客户愿不愿意买单"。

**值得关注的原因**
1. 继 10 月 22 日宇树三季报后，行业"双雄"的量与价口径在同周补齐：宇树 18.17 亿营收 + 智元 9700 台/43% 份额，出货量叙事首次有了双向交叉印证（第三方机构亦将两者列入全球前列）。
2. **Worken 是继宇树报表之后第二个"定度量衡"动作**：机器人从"卖设备"转向"卖有效工时"，与此前"有效智能工时"反超叙事、Genie Master 的 ROI 平衡点一脉相承——具身行业在主动寻找自己的 token 计费单位。该标准能否被第三方与客户采认，是核心检验点。
3. "能造几万台、瓶颈在客户买单"是把 10 月以来需求端的冷数据（真实家庭成功率 12%、科研采购占 55.5%）直接说破：供给已不是约束，需求与单位经济性才是。
4. GO-3 的"最大参数量具身模型"与 70% 研发投大脑，确认全栈路线（模型+本体+运维平台）成为头部共识——彭志辉明言"硬件会折旧，智能会升值"。

## 5. 广东超 2000 台人形机器人进厂：落地量从叙事变成统计口径

**事件内容**
时代财经 10 月 30 日报道（广东省工信厅组织的"人形机器人十骏"产业链走访）：

- 截至 9 月，广东今年已有**超 2000 台**人形机器人进驻制造企业并稳定落地实景场景，全年进厂有望**突破 3000 台**；
- 自变量机器人快递分拣机：每小时超 1800 件（直播峰值 1911 件）；
- 美的"美罗 U"六臂超人形机器人：平均 10 秒打完 6 颗螺丝，作业成功率 99.8%；
- 华沿机器人（今年 3 月港股上市）经验口径：仿真效果好、进真实车间后受光照/来料偏差/振动/油污/节拍影响成功率明显下滑，"只有在真实场景反复打磨才能弥合落差"。

**值得关注的原因**
1. 这是第一个省级、按"进厂且稳定落地"口径统计的人形机器人部署量——与此前 IDC/信通院的出货量口径不同，"稳定在岗"过滤掉了展厅与展会存量，是衡量真实渗透率的更硬指标。
2. 99.8% 打螺丝成功率、1800 件/小时分拣，把"具身能不能干活"的争论从单点演示推进到产线指标；而华沿"仿真到现场成功率下滑"的坦率表述，与 10 月以来"预演/验证前移"的行业主线（ParallelWorld、DR-WM-1.0、Video-to-Sim-to-Real）互为表里。
3. 结合上证报 10 月 30 日研选（人形机器人指数上周 +7.03%、量产爬坡与具身模型共振），资本市场叙事已从硬件零部件切换到"具身模型 + 落地数据"——进厂统计口径的出现恰好提供了后者需要的公开数据源。

## 关键洞察

今天两条线的共同词是**"算账单位"**：

- **coding 侧**：竞争从"谁的 agent 强"转向"谁的账算得清"——OpenAI 用额度翻倍回答"token 值多少钱"，Replit 用 ViBench 2.0 回答"agent 到底能交付多少"（49%–65%），Google 用关停 Jules 回答"哪些产品形态活不下去"。产品收敛与价格分层同步发生，独立异步 agent 工具的窗口期已经关闭。
- **具身侧**：智元 Worken 与广东"2000 台进厂"是同一天出现的两个度量衡——一个想把机器人生产力单位化（像 token 之于 LLM），一个第一次用"稳定在岗"统计真实渗透。供给端（9700 台、年产几万台的能力）与需求端（客户是否买单）的张力继续是行业主矛盾。
- **共同趋势**：昨天是"可审计"，今天是"可计价"。当 PR 占比、token 额度、产品通过率、Worken 工时都成为标价单位，两个行业都在把能力翻译成采购方能比价的数字。

## 口径与可信度提示

1. **Jules 停服**时间线以 IT之家/官方 X 声明为准（11/11 只读、12/31 关闭）；"免费层无对应方案"为 Crypto Briefing 报道口径。
2. **OpenAI 额度调整**为官方 X 宣布，事实明确；"成本下降驱动"为本文推断。
3. **ViBench 2.0** 的 49%–65% 为 Replit 自建基准自报，通过/失败判据（尤其干净部署）细节需看原始文档；OpenHands harness 可复跑是其加分项而非独立验证。
4. **智元数据**（9700 台、43%、GO-3 三榜登顶）均为企业自报，无第三方审计；"43% 全球份额"基于其自有出货口径，与 IDC H1 数据（智元 >8600 台）存在口径差异，不可混用。
5. **广东 2000 台**为省工信厅走访报道口径，统计方法（如何定义"稳定落地"）未公开；单点性能指标为企业现场演示口径。
6. **Copilot Code Review Max**（10/28 公测、多模型评审 agent 聚合、自报 ReviewBench 最高 F1）与"Claude Code 辅助提交密钥暴露率 3.2%（基线 1.5%，第三方分析非 GitHub 口径）"为今日值得跟踪的辅助动态，未单列。
