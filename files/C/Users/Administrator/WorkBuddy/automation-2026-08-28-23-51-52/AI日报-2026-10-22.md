## 1. Anthropic 发布 Claude Duet 研究预览：常驻型个人 Agent 上线（AI Coding / Agent）

**事件**：Anthropic 于 10/21-22 面向美国 Pro/Max 用户开放 Claude Duet 研究预览——一个"主动触达"的常驻 Agent：任务在 Anthropic 云端计算机上持续运行，合盖关机不中断；每天早上主动汇总邮件/日历要点，需要决策或任务完成时主动找用户。付款、签名、发消息、删除等不可逆操作强制人工审批。

**值得关注的原因**：这是 coding agent 厂商第一次把"常驻后台、主动找人"做成产品形态——从"你叫它干活"变成"它替你盯事"。与 OpenAI Dots、Meta Muse 形成同赛道竞争，"审批门"设计（不可逆操作必须人工确认）会直接影响后续各家常驻 Agent 的安全范式。同日 Claude Code 快速迭代至 2.1.307/2.1.308（fork 子智能体防串扰修复、`claude_code.safety_event` OTel 安全事件可观测），多 Agent 并行与安全治理持续深化。

**信源**：Claude Code Daily Briefing 2026-10-22、dailyaithread 工具更新索引

**事件**：10/21 晚 GTC 柏林主题演讲，黄仁勋判断"机器人领域的 ChatGPT 时刻正在迅速逼近"（注意原话是"approaching"而非"已经到来"），提出物理AI 需要具备"客体永久性"等物理常识。核心发布：DSX POD AI 工厂参考设计——Vera Rubin 机柜 + 网络 + 液冷工厂预集成、集装箱交付，部署周期从约 6 个月缩至最快 14 天；DSX MaxLPS 动态供电最高省 30% 用电。生态侧，德国思灵（Agile Robots）发布基于 Isaac GR00T + Jetson Thor 的人形参考平台 Agile ONE SN（31 自由度，2027 年初上市），并与英伟达合作明年生产 1000-2000 台小型人形机器人。

**值得关注的原因**：英伟达没有发新机器人，而是"为时刻到来修路"——把竞争焦点从 GPU 销售转向 AI 工厂交仝速度和机器人工具链。黄仁勋声称物理AI 对应超 50 万亿美元产业机会，A股/港股物理AI 概念股 10/22 延续上涨。判断时态值得注意：行业临界点"在逼近"而非"已跨过"。

## 4. Vercel 开源 durable-harness：编码 Agent 会话崩溃后可恢复（AI Coding / 基建）

**事件**：Vercel 开源 durable-harness——通过记录每一次模型调用与工具调用，将 Agent 会话持久化，Pi、OpenCode、Claude Code、Codex 的会话在崩溃、超时或重新部署后可从断点恢复，记录可存于 Vercel、Postgres 或本地（据 MarkTechPost 报道，发布仅一天，各 CLI 实际兼容度待实测）。

**值得关注的原因**：长任务 Agent 的刚需缺口。近几个月 coding agent 跑得越来越久（Claude Code Projects 数百云端线程、无人值守多日），但"进程一挂全部重来"始终是隐性成本。会话持久化若成为标配，"Agent 可靠性"将像当年的数据库持久化一样从工程技巧变成基础设施。同日 Amp 发布自托管 orbs（企业可用自有基础设施跑 Agent 沙箱），Agent 运行时基建在一天内两度推进。

**信源**：AI雷达日报 2026-10-22、Havoptic

## 5. 首批六项人形机器人国家标准发布，明年 4 月 1 日实施（具身智能 / 政策）

**事件**：市场监管总局批准发布首批六项人形机器人领域国家标准——5 项技术要求系列标准（本体构成、系统架构、环境感知、智能决策等关键功能与性能指标）+《人形机器人仿真测试平台技术规范》（统一可信、可复现的评价方法），2027 年 4 月 1 日正式实施。同期，商务部等 9 部门发文推动具身智能技术在商贸领域落地（家庭服务、商贸物流场景）。

**值得关注的原因**：标准先行 + 需求侧政策，说明监管层正把具身智能从"表演/融资叙事"推向"可检验的产业"。仿真测试平台标准尤其关键——此前行业估值争议的核心就是缺乏统一可信的评价口径，这一标准直接回应了"有效智能工时"之争。

**信源**：央视新闻（电子工程专辑转引）
