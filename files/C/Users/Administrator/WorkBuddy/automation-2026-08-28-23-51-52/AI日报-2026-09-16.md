## 1. Opus 5.2 静默灰度上线 Claude Code：模型发布不再开发布会，RSI 传闻首次摆上台面

**事件**：多名开发者通过抓包和 Claude Code 的 `/status` 发现，前端显示 Opus 5，后端模型 slug 实际已指向 Opus 5.2，疑似跳过 5.1 直接灰度。社区实测反馈高度一致：生成速度显著提升、输出更精简、长任务中会自动进入"严酷循环"（gauntlet loop）——自己写、自己测、自己改，直到交付可运行代码，不再要求用户"按继续"。社区甚至流传一个"探针"：关闭联网询问"重置哥 Tibo 是谁"，新旧权重答案不同可判断是否被切到 5.2。

**需注意的可信度边界**：另据 8 月泄露的内部风险报告口径，Anthropic 内部未发布模型 Model 2 已接管公司大部分代码编写（CoBench v2 得分 62.8，高于最强公开模型约 12.5 分），RSI（递归自我改进）模型或可替代 85% 研究团队工作。**以上 Model 2/RSI 数字均未获官方确认，应按传闻理解**；但 5.2 灰度与长任务自主迭代为社区可复现实锤。

**值得关注的原因**：
- 发布方式变了——头部实验室开始用"静默路由"直接向存量订阅用户灰度新模型，无公告、无版本号，能力供给变成持续交付；
- 恰在 Anthropic CEO 上周末公开呼吁"AI 降速"之后灰度更强模型，治理表态与商业推进形成鲜明反差；
- 无论 RSI 是否属实，"更强模型辅助研发下一代模型"的飞轮叙事首次从论文走向产品口径，值得持续跟踪验证。

## 2. JetBrains 第十届开发者生态调查：终端打败 IDE，Claude Code 使用率 39% 反超 Copilot

**事件**：JetBrains 发布覆盖 1.5 万名专业开发者的年度调查（采样 2026 年 5–7 月）：90% 的开发者每周至少用一次 AI agent，68% 每天使用。格局发生反转——Claude Code 工作场景使用率从 1 月的 18% 升至 39%（美国达 47%），Codex 从 3% 升至 16%；GitHub Copilot 从一年前的 29% 跌至 21%，Cursor 从 18% 跌至 12%（中国市场从 28% 跌至 16%）。31% 的开发者将 Claude Code 列为最常用工具——试过的人约八成留为主力，转化率罕见。

**值得关注的原因**：
- 分水岭不在界面而在"交互单位"：上涨的 Claude Code、Codex、OpenCode 都能脱离 IDE 独立运行、以终端为自然落点；下跌的 Copilot、Cursor 住在编辑器里。竞争已从"补全半行代码"转向"交付一整件事"；
- 这是卖 IDE 的公司自己发布的不利于 IDE 的数据，信号强度高于普通第三方报告；
- 对工具厂商的启示：IDE 的护城河正在从"编辑体验"迁移到"任务编排与执行环境"。

## 3. 字节发布国内首个团队智能体"豆包工作伙伴"，飞书 8.0 为 Agent 系统性重构

**事件**：9 月 15 日飞书未来无限大会，字节整合豆包、飞书、火山引擎后首次集中亮相：飞书 8.0 全面向 Agent 开放数据与工具能力，人能在飞书里做的工作 Agent 几乎都能做（写文档、操作多维表格、排日程、参会、走审批）；支撑底座飞书 CLI 开放功能点从 247 个增至 767 个，调用成功率从 78% 提至 95%。同步发布的"豆包工作伙伴"是国内首个团队智能体产品——拥有独立身份、权限和记忆，像同事一样加入群聊，企业统一配置其权限与用量；权限始终与使用者一致，员工看不到的信息 Agent 也拿不到。梁汝波定性："Agent 进入可用阶段后，Agent、模型与协作环境三者必须紧密融合。"

**值得关注的原因**：
- 与昨日 GitHub 热榜"团队级 agent 配置治理"主题（teamai-cli 等）形成中外呼应：agent 从个人助手升级为组织成员，治理层成为产品核心竞争力；
- 协作平台第一次为 Agent 而非人重构权限体系（Agent 即"一等公民"），企业上下文成为 AI 办公赛道的新护城河；
- 值得留意 TRAE、扣子先后并入豆包体系——AI 编程与办公协同的边界正在字节内部被主动打破。

## 4. 宇树发布 G1+：万台级出货平台的增量迭代，标配 9.5 万元

**事件**：9 月 14–15 日，宇树科技发布 G1 人形机器人迭代版 G1+，围绕运动、感知、交互、续航完成六项升级：头部新增 2 个颈部自由度（俯仰约 -25°~36°、偏航 ±110°），头部可独立转动观察而不必整体转向；肩腰电机峰值扭矩提升 110%（同扭矩发热降 72%），手臂峰值扭矩提升 43%；双目+广角单目+3D 激光雷达组合感知；前 4 后 2 六麦克风阵列；新增 DC 54.6V/5.7A 外接供电口支撑长时间在线。标准版含税 9.5 万元（首发版为 9.9 万元起）。G1 系列自 2024 年 5 月发布以来累计出货超 1.8 万台，2025 年出货超 5500 台、占全球人形机器人市场近三成。

**值得关注的原因**：
- 策略信号：不做推倒重来，而是在已验证平台上做增量升级（评论普遍类比 DJI 的迭代打法）——规模化平台开始按"车型年款"节奏演进；
- 颈部自由度看似小改，实则是把感知自由度从整机解耦出来，直接改善具身模型的观测效率，属"为模型让路"的硬件设计；
- 隐忧与看点并存：招股书显示宇树人形收入中科研教育占 73.6%、工业不足 10%，G1+ 的硬件补强能否打开科研以外的第二曲线，是下一个观察点。

## 5. 具身智能数据集质量标准定档 11 月 1 日实施；统计局数据：8 月工业机器人产量 +34.6%

**事件**：据新华社报道，中国信通院联合 40 余家单位起草的行业标准《具身智能数据集质量要求及评估方法》将于 11 月 1 日正式实施——填补具身智能数据方向标准空白，数据集建设从"规模导向"转向"质量导向"。同期，全国已有超 70 家具身智能训练场投入使用，正从"有没有"转向"好不好"，商业模式向覆盖数据生产、模型训练、应用验证的"训练即服务"转型；工信部、国务院国资委 6 月启动的人形机器人与具身智能实景实训专项行动要求每省至少遴选 20 个重点场景单元。宏观侧，国家统计局公布 8 月机器人减速器产量同比 +11.4%、工业机器人 +34.6%，我国人形机器人出货量全球占比升至 97%；人社部等部门发布的 11 个新职业中，"机器人训练师"正式定名为"具身智能机器人应用技术员"。

**值得关注的原因**：
- 标准（11/1 定档）、新职业（正式定名）、官方统计（+34.6%）同日出现，三者都是"产业基础设施化"的标志——行业话语体系从 demo 指标切换为可审计的国家口径；
- 对数据供应商与训练场运营方：质量导向标准落地后，以量取胜的数据售卖模式面临重估，"训练即服务"或成新分水岭；
- 97% 的全球出货占比意味着中国已深度绑定全球人形机器人供应链，后续标准与统计口径可能成为国际竞争中的事实基准。

## 今日主线

两条线都在从"发布"走向"渗透"：
- **AI coding 侧**：能力供给方式变了（静默灰度替代发布会），市场格局出现分化（终端型 agent 胜、编辑器型工具退），协作平台开始为 agent 重构组织权限；
- **具身智能侧**：产品按平台节奏迭代（G1+），标准与职业体系落地定档，宏观统计首次给出 97% 出货占比的官方口径——行业正在被"制度化"。
