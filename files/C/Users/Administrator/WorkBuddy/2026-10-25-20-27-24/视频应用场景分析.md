## 二、应用场景分析

### 场景 1：主题班会 / 开学第一课 / 学习动员（★韩雅平素材最佳）
- **切入点**：自律与内驱力。她"每周 20 元零花钱原封退回""吃饭比同学快、多啃错题"等细节对中学生有极强的代入感。
- **视频用法**：用《小莉帮忙》短采访做开场（1 分钟内抛出"699 分 + 寒门"的反差），随后进入"她是怎样学习的"内容页。
- **配套素材**：28 张奖状墙照片、高考各科分数卡（语文 132/数学 144/英语 146）、金句"不吃学习的苦，就要吃生活的苦"。
- **注意**：她曾遭网暴，班会中建议聚焦其奋斗过程，不宜渲染网络争议，引导重点是"尊重他人、专注自己"。

### 场景 2：道德讲堂 / 事迹报告会 / 文明创建活动（★陈新超素材最佳）
- **切入点**：平凡岗位上的不平凡。2026 年"中国好人榜"候选人、"荆楚楷模"身份自带权威性。
- **视频用法**：用《新时代的我们》7 分钟档专题片做主体播放；《党员风采》版作为备选。
- **配套素材**：数据卡（120 公里/天、400 件包裹/天、20 多万公里、2.3 万村民）、零钱盒与顺风车两个暖心细节、金句"荣誉不如村民一句'辛苦了'实在"。

### 场景 3：党员学习 / 党课 / 主题党日（★陈新超《党员风采》版最佳）
- **切入点**：党员先锋模范作用。她是阳新县首个快递行业党支部里唯一的女党员，"我是党员，应该做榜样"可直接做标题。
- **结构建议**：入党初心（为挣钱治病 → 为乡亲服务）→ 岗位奉献 → 精神升华，与"我为群众办实事"衔接。

### 场景 4：感恩教育 / 家长会 / 助学公益宣传（★韩雅平《时光里》故事线最佳）
- **切入点**：双向奔赴的善意。"顾妈妈"顾虹 12 年助学 → 韩雅平 699 分回响 → 50 位爱心人士加入，是公益助学最完整的叙事闭环。

4. **备注**：韩雅平及家人已公开表示希望回归平静生活，素材使用请保持克制，避免过度消费当事人。
