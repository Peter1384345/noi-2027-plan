# CSP-J/S 复赛抢分技巧与题型分析手册

> **用途说明**：本文档为复赛比赛专用抢分技巧（应试抢分策略），仅限比赛时使用，平时训练不能依赖。核心思路：盯紧数据范围，倒推得分点，确保 4 道题的保底分全部拿到后，再去攻坚正解。

---

## 一、核心抢分策略：按数据范围拿分

题目的数据范围绝对能骗到分，多少的问题。按以下几种情况处理：

### 1. 特判边界情况（n=0 或 n=1）
- 当 `n = 0` 或 `n = 1` 时，值是多少，**一定要用 if 写出来**。
- 写出来就是 **10~20 分**，绝对的。

### 2. 小数据直接暴力（n < 10）
- 当 `n < 10` 时，直接 DFS 暴力，枚举 1~10 之间 n 的所有可能性并输出答案。
- 不会超时，也有 **10~20 分**。

### 3. 中等数据降级算法（n < 5000）
- 当 `n < 5000` 时，把算法降到 **O(n²) 级别**——想办法压缩到一个 for 嵌套一个 for 算出来。
- 这 **30 分** 也能拿。

### 4. 后面的优化分：放弃
- 没思路的情况下，**一定一定要**按上面三步走，把保底分拿满。

## 三、CSP-J/S 近年规律分析

### （一）J 组：题号题型高度固化，定位极其稳定

近 7 年 J 组 4 道题的功能分层非常固定，备考可以直接按题号针对性训练：

1. **T1 纯签到题**：不涉及复杂算法，本质是「遍历 + 计数 / 简单模拟」，考点集中在字符串、桶计数、基础数学模拟，代码量极小，是**必须满分的题**。丢分几乎都来自数据范围溢出、文件名写错等细节失误。
2. **T2 模拟 / 基础算法题**：以排序、贪心、前缀和 / 差分为核心考点，思维难度低，主要考验代码实现的细心度，正常训练目标也是冲满分。近年前缀和思想有从 T4 下沉到 T2 的趋势。
3. **T3 中档分水岭**：以数学推导、构造、性质观察为核心，连续多年设置「性质 A/B/C」的送分档，暴力 + 基础性质就能拿 70~80 分，满分解需要一定的思维推导能力，是**奖项区分的核心题**。
4. **T4 压轴题**：以基础 DP（背包、线性 DP）、简单图论搜索为主，满分难度高，但暴力 DFS、朴素 DP 稳定能拿 20~30 分保底，是高分选手拉开差距的地方。

#### 考点与得分特点

- **考点严格限定在入门范围**：只考模拟、贪心、排序、枚举、搜索、基础 DP、简单数论，完全不涉及高级数据结构（线段树、平衡树等均不考察）。
- **骗分性价比极高**：只写基础暴力代码，就能拿到 240~290 分左右的保底分，刚好覆盖多数省份一等奖的门槛区间，这是 J 组最核心的应试策略。
- **区分度集中在后两题**：前两题大部分选手都能接近满分，拉不开差距；获奖排名基本由 T3、T4 的部分分完成度决定。

### （二）S 组：难度跃迁更明显

S 组 4 道题的难度跃迁比 J 组更明显，对应不同水平选手的得分目标：

1. **T1 基础签到题**：难度接近 J 组 T2~T3，近年趋势是「包装成大模拟的贪心 / 简单数学」，题面长但核心逻辑简单，细心实现就能拿满，是所有选手的必拿分。
2. **T2 中档核心分水岭**：考察核心是「建模能力」——把生活化的题目场景翻译成经典算法模型，常见考点是二分答案、贪心、前缀和、区间 / 树形 DP、基础图论。大部分选手能拿 60~80 分，**能不能冲一等奖基本看这题的完成度**。
3. **T3 中高档难题**：一般是字符串处理、进阶 DP、中等数据结构（Trie、线段树基础应用）或图论进阶，满分门槛高，但子任务梯度充足，暴力 + 特殊性质能稳定拿 50~70 分。
4. **T4 压轴难题**：多为跨模块综合题，覆盖高级 DP、复杂图论（网络流、树上高级算法）、高级数据结构，普通选手只能拿 10~30 分暴力分，是省队级高分选手的核心区分点。

#### 核心考点趋势

- **思维权重持续上升，纯码量题减少**：早年的大模拟题占比明显下降，现在更看重「问题转化」能力，很多题是"想得到就几行代码，想不到就只能暴力"，单纯背模板的收益降低。
- **DP 和图论是绝对重点**：每年至少 2 道 DP 相关题目，图论题占比接近 40%；考察方向从"经典算法默写"转向"场景建模"，比如把实际问题转化为最短路、最小生成树模型。
- **数学 / 构造占比大幅提升**：数论、组合数学、性质推导类题目占比从 20% 涨到 30%+，和 J 组呼应，都喜欢设置特殊性质子任务，引导选手逐步推导正解。
- **跨模块综合题成为常态**：一道题结合字符串 + 数据结构、图论 + DP、数学 + 贪心等多个模块，考察「拆解问题 → 归结到已知算法 → 组合求解」的综合能力，而非单个知识点的记忆。

## 四、2026 题型预测（仅供参考，不一定准；考场压错不要心态崩）

### （一）CSP-J（入门组）2026 题型预测

#### T1 签到题（目标：满分）

- **预测考点**：字符串基础处理 / 桶计数 / 简单数学模拟
- **命题逻辑**：延续"零算法门槛，纯细心拿分"的定位，没有复杂逻辑，代码量通常 30 行以内。
- **考法说明**：近三年分别考了数组模拟、字符串标记、计数排序，今年轮换到字符串遍历统计、简单数学运算模拟的概率最高，属于必须拿满的送分题。

#### T2 基础算法 / 模拟题（目标：冲满分）

- **预测考点**：排序贪心 / 区间模拟 / 前缀和基础应用
- **命题逻辑**：以"实现难度"为核心区分度，思维量低，主要考验代码细节和边界处理。
- **考法说明**：前两年分别考了纯贪心和纯大模拟，今年大概率是"排序 + 贪心"的结合，或者带前缀和技巧的流程模拟题，正常训练完全可以冲满分。

#### T3 中档分水岭（目标：保 70 冲满分）

- **预测考点**：数学性质推导 / 简单构造 / 线性 DP
- **命题逻辑**：延续"子任务分档"设计，暴力能拿 30~50 分，找到核心性质就能拿 70~100 分，是决定奖项等级的核心题。
- **考法说明**：近三年分别是数学方程、数学构造、异或 DP，今年大概率还是数学性质类题目，会明确标注「性质 A/B」的送分档，**优先把性质分全部写满**。

#### T4 压轴题（目标：保 20~30 分，冲更高）

- **预测考点**：线性 DP / 背包变种 / 基础图论搜索（DFS/BFS）
- **命题逻辑**：满分难度高，但暴力分丰厚，朴素搜索或简单 DP 就能稳定拿到保底分。
- **考法说明**：近三年分别是图论 DFS、接龙 DP、背包计数，今年轮换到图论基础（树上遍历、带条件的最短路）的概率较高，也可能是区间 DP 入门。

### （二）CSP-S（提高组）2026 题型预测

#### T1 基础签到题（目标：满分）

- **预测考点**：大场景包装的贪心 / 模拟 / 简单数学推导
- **命题逻辑**：题面通常很长，包装复杂生活场景，但核心逻辑极其简单，本质是"去包装"的送分题。
- **考法说明**：不会考复杂算法，核心考验读题提炼能力，避免被长题干吓住，提取核心规则细心实现即可拿满。

#### T2 算法建模题（目标：冲一等奖核心，强烈怀疑会有树）

- **预测考点**：二分答案 / 前缀和优化 DP / 基础图论建模
- **命题逻辑**：核心考察「问题转化能力」——把生活化场景翻译成经典算法模型，是区分一等奖和二等奖的关键题。
- **考法说明**：弱化纯模板默写，强化场景建模，不会直接出"求最短路"这类裸题，需要自己把问题对应到二分、DP、最短路等经典模型。

#### T3 中高档难题（目标：保 50~70 分）

- **预测考点**：**树形 DP（重点！去年 NOIP 已出现树形 DP，板子一定要会）** / 字符串算法（KMP/Trie） / 基础数据结构应用
- **命题逻辑**：子任务梯度明显，暴力 + 简单性质能拿过半分数，满分解需要掌握进阶算法和优化技巧。
- **考法说明**：今年考树形 DP 或字符串匹配的概率较高，也可能是线段树 / 树状数组的基础应用，优先拿完小数据和性质分。

#### T4 压轴综合题（目标：拿满暴力分）

- **预测考点**：图论 + DP 综合 / 数据结构优化 DP / 复杂图论算法
- **命题逻辑**：省队级区分题，普通选手目标是拿满小数据暴力分，不硬磕正解。
- **考法说明**：通常是跨模块综合题，子任务从 n≤20 的暴力分到 n=1e5 的正解分梯度排布，优先写搜索、朴素 DP 拿保底。

## 五、题型快速判断：关键词眼 + 识别技巧

### 1. 模拟题

- **核心关键词**：规则、流程、依次、逐次、操作步骤、游戏过程、最终状态
- **快速判断**：题面大段描述操作规则，问"最终结果 / 状态"，没有"最少、最多、最优"等极值要求，纯按要求写代码即可。
- **常见题号**：J 组 T1、T2；S 组 T1

### 2. 贪心题

- **核心关键词**：最少、最多、最小代价、最大收益、尽可能、优先、相邻、排序
- **快速判断**：求最优解，且直觉上"按某种顺序选择"就能得到答案，通常排序是核心前置步骤。
- **常见题号**：J 组 T2、T3；S 组 T1、T2

### 3. 数学 / 构造 / 性质题

- **核心关键词**：性质 A/B、满足条件、构造、公式、倍数、约数、奇偶性、异或、规律
- **快速判断**：有明确的子任务分档（比如"30% 数据暴力，60% 满足某性质"），纯暴力会超时，但推导数学规律后代码极短。
- **常见题号**：J 组 T3；S 组 T2、T3

### 4. 动态规划（DP）题

- **核心关键词**：方案数、计数、最大价值、最小代价、选 / 不选、前 i 个、子序列、背包、接龙
- **快速判断**：求方案数、求极值且贪心显然不成立，数据范围在 n=100~1e4 之间，优先考虑 DP。看到"计数""方案数"90% 概率是 DP。
- **常见题号**：J 组 T3、T4；S 组 T2、T3、T4

### 5. 搜索题（DFS/BFS）

- **核心关键词**：所有方案、枚举、路径、到达、连通、n≤20、小数据
- **快速判断**：数据范围极小（n≤20/30），或者求所有可行解，直接写暴力搜索保底，是压轴题骗分的核心手段。
- **常见题号**：J 组 T4；S 组 T3、T4 的小数据分

### 6. 图论题

- **核心关键词**：节点、边、路径、连通、最短路、树、图、道路、地点、距离
- **快速判断**：明确给出点和边的结构，或者场景是"地点 + 道路""站点 + 线路"，本质都是图模型。
- **常见题号**：J 组 T4；S 组 T2、T4

### 7. 数据结构题

- **核心关键词**：区间修改、区间查询、单点修改、多次查询、第 k 大、前缀和、差分
- **快速判断**：有多次修改 + 多次查询，数据范围 n, q ≥ 1e4，暴力 O(nq) 超时，需要数据结构优化。J 组基本不考高级数据结构，S 组 T3/T4 出现。

## 六、一秒定位的辅助技巧

### 1. 先看数据范围

| 数据范围 | 对应算法方向 |
|----------|--------------|
| n ≤ 20 | 暴力搜索 / 状态压缩 DP |
| n ≤ 1000 | O(n²) DP / 暴力枚举 |
| n ≤ 1e5 | O(n log n) 贪心 / 排序 / 数据结构 / 二分 |

### 2. 再看问题类型

- 问"行不行 / 能不能" → 二分答案、搜索
- 问"多少种方案" → DP、组合数学
- 问"最少 / 最多" → 贪心、DP、图论最短路

### 3. 按题号预判方向

- **J 组**：按「T1 模拟 → T2 贪心 / 模拟 → T3 数学 → T4 DP / 图论」的惯性先预设方向，读题验证即可。
- **S 组**：按「T1 简单 → T2 建模 → T3 进阶 → T4 综合」的梯度预判，能大幅节省读题思考时间。
