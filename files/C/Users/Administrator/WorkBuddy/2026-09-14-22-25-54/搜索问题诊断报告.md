# Windows 搜索问题诊断报告

**日期**:2026-09-14
**系统**:Microsoft Windows 11 专业版,Build 26200,64 位
**问题**:开始菜单搜索不到"注册表编辑器"(regedit)等系统工具

---

## 一、诊断结论

### 核心原因 1:App Paths 注册表项被批量删除(已确认)

Windows 开始菜单搜索依赖以下注册表位置识别系统程序:

```
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\App Paths
```

检查发现,系统自带的 App Paths 键**全部缺失**:

| 缺失的键 | 对应程序 | 原始文件位置 | 文件是否还在 |
|---|---|---|---|
| regedit.exe | 注册表编辑器 | C:\Windows\regedit.exe | ✅ 完好 |
| mspaint.exe | 画图 | C:\Windows\System32\mspaint.exe | ❌ 已被删 |
| notepad.exe | 记事本 | C:\Windows\System32\notepad.exe | ❌ 已被删 |
| control.exe | 控制面板 | C:\Windows\System32\control.exe | ✅ 完好 |
| winver.exe | 关于 Windows | C:\Windows\System32\winver.exe | ✅ 完好 |

- 当前 App Paths 下只剩第三方软件的键(7-Zip、VLC、VMware、Edge 等)
- regedit.exe 文件本身完好,`Win+R` 输入 `regedit` 仍可用,但搜索栏搜不到
- mspaint.exe、notepad.exe 连文件都被删了,属于系统精简过度

### 核心原因 2:搜索索引数据库缺失(疑似)

- WSearch(Windows Search)服务正常运行,SearchHost / StartMenuExperienceHost 进程正常
- 但索引数据库目录 `C:\ProgramData\Microsoft\Search\Data\Applications\Windows` 为空(正常应存在 Windows.edb)
- 索引从未成功建立或被清理过,导致依赖索引的搜索内容(应用、设置、文件)无结果

### 其他发现

- `SysMain` 服务被停止且禁用(典型"系统优化"痕迹,会拖慢搜索和应用启动)
- 该系统曾被"优化/精简"工具处理过,删掉了部分系统组件和注册表项

已生成一键修复脚本:`wb_fix.ps1`(与本报告同目录)

**执行方法**:
1. 右键开始菜单 → 选择"终端(管理员)"或"Windows PowerShell(管理员)"
2. 执行:


脚本将执行(均为低风险、可逆操作):

**修复后**:

## 三、二次诊断:为什么"只有英文能搜到、中文搜不到"(2026-09-15)

### 真正根因:系统工具的中文显示名丢失

逐层验证结果:

| 检查层 | 结果 |
|---|---|
| 索引作用域 | ProgramData 开始菜单已收录;用户 AppData 开始菜单**未被收录**(缺少默认 Include 规则) |
| 索引内容 | 5552 项,含 107 个快捷方式,"Windows 工具\注册表编辑器.lnk"**已在索引中** |
| 中文分词匹配 | `CONTAINS("注册表")` 能精确命中该快捷方式 —— **索引层完全正常** |
| 开始菜单应用清单(shell:AppsFolder) | 130 项,但系统工具**全部显示英文**:Registry Editor / Event Viewer / Task Manager / Computer Management… |

**结论**:中文搜索失败不在索引,而在于系统工具的显示名是英文。原因链条:

1. 系统工具的中文名来自目标程序的中文语言资源文件(MUI)
2. `C:\Windows\System32\zh-CN\` 下的 `regedit.exe.mui`、`control.exe.mui`、`notepad.exe.mui` 等被精简工具删除(WinSxS 无备份)
3. 显示名无法本地化,回落为英文 → 中文关键词匹配不上,英文关键词可匹配

对比验证:UWP 应用(微信、计算器、记事本、设置)显示中文正常;已有的中文项(命令提示符、文件资源管理器)是因为快捷方式文件名本身是中文。

### 已实施的替代修复(无需管理员权限、不改系统文件)

在开始菜单用户目录创建**中文名快捷方式**,让开始菜单出现中文条目:

- 已创建:`%AppData%\Microsoft\Windows\Start Menu\Programs\注册表编辑器.lnk` → `C:\Windows\regedit.exe`
- 验证:AppsFolder 清单中已出现"注册表编辑器"中文条目

该方案完全可逆(删除该 .lnk 即可),不动任何系统文件。

### 彻底修复方案(需提权)

若希望所有系统工具恢复中文名,仍需补回 MUI 语言资源,见 `wb_fix2.ps1`(sfc /scannow + 补索引范围规则)。
