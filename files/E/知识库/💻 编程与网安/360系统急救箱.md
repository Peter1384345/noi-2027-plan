# 360 系统急救箱

> 360 系统急救箱工具集合，用于系统修复、病毒查杀、DLL 修复等场景。

## 文件位置

**原始路径：** `C:\Users\Administrator\Desktop\总文件夹\资料整合\360compkill64\`

## 包含内容

| 文件 | 说明 |
|------|------|
| Superkiller.exe | 超级杀手主程序 |
| SuperKillller.exe | 超级杀手（备用） |
| Administrator-13509-.exe | 急救箱主程序 |
| 360Base64.dll | 360 基础库 |
| 360NetBase64.dll | 360 网络库 |
| 360Util64.dll | 360 工具库 |
| fixtool.ini | 修复工具配置 |
| SysRepair.log | 系统修复日志 |
| ave/ | 病毒库目录 |
| dyn/ | 动态特征库 |
| Fix/ | 修复模块 |

## 使用场景

- 系统被病毒感染导致无法正常运行
- exe 文件无法执行时使用急救箱
- DLL 文件被篡改或损坏
- 系统关键设置被恶意修改

## 使用说明

1. 正常情况直接运行 `Superkiller.exe`
2. 如 exe 无法运行，先双击 `所有360程序无法运行时请双击.com`
3. 仍无法运行时，将急救箱复制到其他目录改名后运行
4. 解压密码：123（如需要）
