# C++信息学奥赛学习平台

> 参考Brilliant.org风格的C++信息学奥赛学习网站

## 项目概述

- **技术栈**: HTML + JavaScript + ECharts + Mermaid.js
- **部署**: GitHub Pages
- **本地运行**: `http://localhost:8080`

## 核心功能

### 学习路线图
- 一个月C++奥赛学习计划（从零开始）
- 每日打卡系列，每天对应一个知识点
- 概念 → 互动练习 → 挑战三步学习法

### 视频课程
- B站视频嵌入（缩略图+播放按钮，非iframe）
- 视频封面下载到本地服务器
- 新窗口打开视频链接

### 挑战题目
- 对应洛谷题目（B2002, B2003等）
- 标题、内容、外链三者匹配
- 进度追踪（localStorage `day-N-checked`）

### AI功能模块（6大模块）
1. 苏格拉底式引导学习
2. AI学习助手
3. 智能题目推荐
4. 代码审查
5. 学习路径规划
6. 实时资源获取

### 数据管理
- 数据备份与恢复功能
- 学习记录localStorage存储

## 项目记忆

### 硬约束
- B站视频用缩略图+播放按钮，不用iframe（跨域问题）
- server.js必须用`__dirname`而非相对路径
- 外链必须`target="_blank"` + `rel="noopener noreferrer"`

### 经验教训
- B站合集BV号（非独立视频）导致iframe嵌入失败
- 洛谷P1000不适合Day1，应用B2002
- CDN回退机制有加载时序缺陷，导致echarts/mermaid初始化失败
- 关闭B站标签页可能残留音频进程
