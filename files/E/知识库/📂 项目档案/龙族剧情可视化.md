# 龙族剧情可视化网页

> 《龙族》小说全系列剧情与人物关系可视化网站

## 项目概述

- **本地运行**: `http://localhost:8889/dragon-story.html`
- **在线部署**: Vercel (dragon-story.vercel.app) / Gitee Pages
- **技术栈**: HTML + JavaScript + CSS

## 核心功能

### 内容板块
- 人物关系图谱（含非主角角色）
- 炼金术与科技板块
- 角色头像与介绍
- 剧情时间线
- 更新按钮（自动更新内容）

### 设计特色
- 多层次背景色彩升级
- 板块扩展与新增
- 圆形角色头像
