# 魔法单词学院 (Magic Word Academy)

> 从小学到雅思水平的英语单词记忆软件，魔法学院主题风格

## 项目概述

- **项目路径**: `D:\TRAE SOLO CN\magic-word-academy\`
- **桌面启动器**: `D:\TRAE SOLO CN\dist\魔法单词学院启动器.exe`
- **在线部署**: GitHub Pages
- **技术栈**: React + TypeScript + Vite + Tailwind CSS

## 核心功能

### 单词学习系统
- **17级词库**: 小学1-6年级、初中7-9年级、高中10-12年级、四级、六级、雅思
- **教材同步**: 3-12年级使用2019新人教版教材词汇
- **盲打模式**: 中译英、发音拼写、英译中
- **发音系统**: 有道API直链MP3 + 浏览器Web Speech API（美音/英音切换）
- **单词图片**: 练习页面展示单词配图
- **经典文本**: 附带中文翻译切换按钮

### 复习机制
- **错词本**: 艾宾浩斯6阶段复习（1/2/4/7/15/30天）
- **入门测试**: 20题≥70%通过，3次失败自动降级
- **管理员跳过**: 管理员用户跳过年级选择和强制测试

### 界面设计
- **魔法学院风**: 淡粉紫+金色+米白，魔法棒、水晶球、小女巫元素
- **启动特效**: 魔法主题启动和页面转场动画
- **电子课本链接**: 各年级直接跳转电子课本

### 账号系统
- 用户名/密码登录
- 本地存储学习进度

## 项目记忆

### 硬约束
- 悬浮球自动吸附屏幕边缘（40px阈值）

- GitHub Actions部署不稳定，直接部署gh-pages分支更可靠
