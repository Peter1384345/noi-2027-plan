## 四、脚本怎么用

`05_制作脚本/` 里的脚本都是 `python-pptx` 批量处理，需要 **`py -3.12`** 启动（系统默认的 3.13 没装这个库）。

**当前在用的是 `05_制作脚本/rebuild/` 这一套**，一条命令重出整本：

| 脚本 | 作用 |
|---|---|
| `rebuild/build_orig.py` | **主构建脚本**：读小组原始版（最老版本）→ 插 7 页新页（新页用小组原始版词汇重做）→ 设自动播放 → 写备注 → 存到 `06_成品输出/` |
| `rebuild/render2.py` | 近似渲染成 png 校对排版（支持渐变、透明度、裁切、theme 色），`py -3.12 render2.py 文件 页码 输出.png`（页码从 0 开始） |
| `rebuild/verify.py` | 逐页导出文字/图片/备注 + 查 zip 内重名 |
| `rebuild/dump.py` | 导出每页每个形状的几何、填充、字体，反推原版式用 |
| `rebuild/contrast.py` | 按 WCAG 算文字与底色对比度，专抓「红底深红字」 |
| `rebuild/vidinfo.py` | 纯 python 读 mp4 显示尺寸（不解码，取 tkhd 末 8 字节） |

`05_制作脚本/` 根目录下是前几轮的历史脚本（`toc_bands.py`、`restore_mini.py`、`bump_small.py` 等），仅作参考。

**删页务必用 `prs.part.drop_rel(rId)` + `sldIdLst.remove()` 两步**，只删后者会在 zip 里留下孤儿 part，导致 `Duplicate name: ppt/slides/slideN.xml`、页码全乱。
